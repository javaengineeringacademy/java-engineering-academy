# HashiCorp Tools

## Overview
HashiCorp provides tools for cloud infrastructure automation.

## Topics
- Terraform (IaC)
- Vault (Secrets)
- Consul (Service Mesh)
- Nomad (Workload Orchestration)
- Packer (Image Building)
- Vagrant (Development Environments)
- Sentinel (Policy as Code)
- Waypoint (Deployment)

## Learning Objectives
- Use HashiCorp ecosystem
- Manage secrets with Vault
- Implement service mesh

## Prerequisites
- DevOps basics
