# Docker Quiz

## Question 1
What is the difference between a Docker image and a Docker container?
- A) They are the same thing
- B) A container is a running instance of an image; an image is a read-only template with instructions for creating a container
- C) An image is always larger than a container
- D) Containers cannot be stopped and restarted

**Answer: B**
**Explanation:** A Docker image is a read-only template containing application code, runtime, and dependencies. A container is a runnable instance of an image with its own filesystem and process. Multiple containers can run from the same image.

## Question 2
What is the purpose of a multi-stage Dockerfile build?
- A) To build multiple containers at once
- B) To separate build-time and runtime dependencies, resulting in smaller final images
- C) To run multiple applications in one container
- D) To create images for multiple operating systems

**Answer: B**
**Explanation:** Multi-stage builds use multiple FROM statements. Build stages compile and package the application, while the final stage copies only the necessary artifacts, excluding build tools and source code, resulting in a much smaller image.

## Question 3
What is a Docker volume used for?
- A) To increase container CPU allocation
- B) To persist data generated by containers beyond their lifecycle
- C) To network containers together
- D) To store Docker images

**Answer: B**
**Explanation:** Docker volumes provide persistent storage that survives container restarts and removals. They are managed by Docker and stored outside the container's writable layer, making them ideal for databases and user data.

## Question 4
What does the `docker-compose.yml` file define?
- A) A single container configuration
- B) Multi-container application configurations including services, networks, and volumes
- C) Docker image build instructions
- D) Kubernetes deployment manifests

**Answer: B**
**Explanation:** `docker-compose.yml` defines a multi-container Docker application. It specifies services (containers), networks (how they communicate), and volumes (persistent storage) for running the entire application stack.

## Question 5
Which Docker instruction copies files from the build context into the image?
- A) `ADD` only
- B) `COPY` (and `ADD` which also supports URLs and tar extraction)
- C) `RUN`
- D) `CMD`

**Answer: B**
**Explanation:** `COPY` copies files and directories from the host filesystem into the image. `ADD` also copies files but additionally supports remote URLs and automatically extracting tar archives. `RUN` executes commands, and `CMD` sets the default command.
