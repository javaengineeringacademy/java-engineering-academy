# Cheat Sheets Quiz

## Question 1
What is the primary purpose of a developer cheat sheet?
- A) To replace official documentation entirely
- B) To provide quick reference for common commands, patterns, and syntax during development
- C) To serve as a tutorial for beginners
- D) To document business requirements

**Answer: B**
**Explanation:** Cheat sheets are concise, quick-reference guides that help developers recall common syntax, commands, and patterns without searching through full documentation. They boost productivity during coding.

## Question 2
When creating a Java cheat sheet, which topics are most commonly included?
- A) Only advanced concurrency patterns
- B) Collections, String operations, Stream API, exception handling, and common annotations
- C) Only database query syntax
- D) Only design patterns

**Answer: B**
**Explanation:** Effective Java cheat sheets cover the most frequently used APIs: Collections framework, String/StringBuilder methods, Stream API operations, exception handling, and commonly used annotations like @Override, @Autowired, etc.

## Question 3
What is the best format for organizing a cheat sheet?
- A) Long paragraphs of explanation
- B) Grouped sections with concise code snippets and one-line descriptions
- C) Full source code listings
- D) Narrative descriptions of concepts

**Answer: B**
**Explanation:** Cheat sheets work best with concise, scannable content: code snippets, tables, and brief descriptions organized by topic. This format allows quick lookup without reading through lengthy explanations.

## Question 4
How often should a developer update their personal cheat sheets?
- A) Never, once created they are permanent
- B) Regularly, as new APIs, language features, and best practices evolve
- C) Only when changing programming languages
- D) Once per year

**Answer: B**
**Explanation:** Technology evolves rapidly. Cheat sheets should be updated when new language versions introduce features (like Java records, text blocks), when tools change, or when best practices evolve.

## Question 5
What makes a cheat sheet effective for team use?
- A) It should be as long as possible
- B) It should be version-controlled, shared, and kept consistent with project conventions
- C) It should be printed and laminated
- D) It should only contain advanced topics

**Answer: B**
**Explanation:** Team cheat sheets should be version-controlled (in the repo), shared among team members, reflect project-specific conventions and tools, and be updated as the team's tech stack evolves.
