# Data Engineer Learning Path

## Overview
Roadmap for building data pipelines and data platforms.

## Stage 1: SQL & Databases
- Advanced SQL
- Relational database design
- Query optimization

## Stage 2: Programming
- Python for data
- Java/Scala basics
- Shell scripting

## Stage 3: Big Data
- Hadoop ecosystem
- Apache Spark
- Hive/HBase

## Stage 4: Data Warehousing
- Star/snowflake schemas
- ETL/ELT processes
- Data modeling

## Stage 5: Stream Processing
- Apache Kafka
- Apache Flink
- Real-time analytics

## Stage 6: Data Platform
- Data lake architecture
- Delta Lake/Iceberg
- Data governance

## Certifications
- Google Cloud Data Engineer
- AWS Data Analytics
- Databricks Certified Data Engineer
