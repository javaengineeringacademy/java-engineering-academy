# Python Testing Exercises

## Learning Objectives
- Master unittest framework
- Understand pytest features
- Write effective test cases
- Use fixtures and mocking
- Implement test-driven development

## Exercises

### unittest_basics.py
1. **Calculator Tests** (Easy) - Basic unittest patterns
2. **String Formatter Tests** (Medium) - Test edge cases
3. **Mock Database** (Medium) - Use unittest.mock
4. **Exception Testing** (Medium) - Test exception handling
5. **Test Fixtures** (Medium) - Setup and teardown

### pytest_basics.py
1. **Pytest Fixtures** (Easy) - Basic fixture usage
2. **Parametrized Tests** (Medium) - Test multiple inputs
3. **Mocking with pytest** (Medium) - pytest-mock usage
4. **Conftest and Plugins** (Medium) - Shared fixtures
5. **Markers and Skipping** (Medium) - Test organization

## Tips
- Write tests that are independent
- Follow Arrange-Act-Assert pattern
- Test both success and failure cases
- Use descriptive test names
- Aim for high coverage but focus on critical paths
