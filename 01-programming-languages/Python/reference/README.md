# Reference

Quick-reference guides for Python best practices, anti-patterns, performance tips, and comparisons.

## Contents

| File | Description |
|------|-------------|
| best-practices.md | idiomatic Python patterns and conventions |
| anti-patterns.md | common mistakes and how to avoid them |
| performance.md | profiling tips and optimization strategies |
| comparison.md | Python vs other languages |
| patterns.md | design patterns and when to use them |

## Prerequisites

- Python Fundamentals (01-fundamentals)

## Learning Objectives

By the end of this module you will be able to:

- Identify and avoid common Python anti-patterns
- Apply best practices for readable, maintainable code
- Profile and optimize Python programs
- Compare Python's approach to other languages
