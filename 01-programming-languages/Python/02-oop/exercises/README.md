# Python OOP Exercises

## Learning Objectives
- Design and implement classes with proper encapsulation
- Implement inheritance and polymorphism
- Use special methods (dunder methods)
- Apply composition over inheritance
- Practice design patterns

## Exercises

### classes.py
1. **Bank Account** (Easy) - Create a BankAccount class with deposit/withdraw
2. **Vector Class** (Medium) - Implement a 2D vector with operations
3. **Stack Implementation** (Medium) - Create a Stack class with LIFO behavior
4. **Shopping Cart** (Medium) - Build a ShoppingCart class with item management
5. **Singleton Pattern** (Hard) - Implement the Singleton design pattern

### inheritance.py
1. **Animal Hierarchy** (Easy) - Create base Animal class with subclasses
2. **Shape Calculator** (Medium) - Polymorphic shape classes
3. **Employee System** (Medium) - Different employee types with bonuses
4. **Custom Exception Hierarchy** (Medium) - Build exception classes
5. **Plugin System** (Hard) - Create an extensible plugin architecture

## Tips
- Always define `__repr__` and `__str__` for debugging
- Use properties for controlled attribute access
- Prefer composition when "has-a" relationship exists
- Use abstract base classes for interfaces
- Follow SOLID principles
