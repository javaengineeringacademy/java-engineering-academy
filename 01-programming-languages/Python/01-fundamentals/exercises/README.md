# Python Fundamentals Exercises

## Learning Objectives
- Master Python basics: variables, data types, and operators
- Understand control flow (if/else, loops)
- Work with functions and scope
- Manipulate strings, lists, dictionaries, and tuples
- Practice file I/O and error handling

## Exercises

### basics.py
1. **Temperature Converter** (Easy) - Convert between Celsius and Fahrenheit
2. **List Manipulation** (Easy) - Reverse, flatten, and filter lists
3. **String Palindrome Checker** (Easy) - Check if a string is a palindrome
4. **Dictionary Merge** (Medium) - Merge two dictionaries with conflict handling
5. **FizzBuzz Extended** (Medium) - Classic FizzBuzz with custom rules

### intermediate.py
1. **Prime Number Generator** (Medium) - Generate primes using Sieve of Eratosthenes
2. **Matrix Transposer** (Medium) - Transpose a 2D matrix
3. **File Word Counter** (Medium) - Count word frequencies from a file
4. **Recursive Fibonacci** (Medium) - Implement memoized Fibonacci
5. **Error Handler Decorator** (Hard) - Create a decorator for retry logic

## Tips
- Start with the easier exercises and work your way up
- Use Python's built-in functions when appropriate
- Write clean, readable code with proper variable names
- Test your solutions with the provided test cases
