# Python Advanced Exercises

## Learning Objectives
- Master decorators and closures
- Understand generators and iterators
- Apply context managers
- Work with metaclasses and descriptors
- Implement advanced design patterns

## Exercises

### decorators.py
1. **Timer Decorator** (Easy) - Measure function execution time
2. **Cache/Memoize Decorator** (Medium) - Cache function results
3. **Rate Limiter** (Hard) - Limit function call frequency
4. **Type Checker Decorator** (Medium) - Validate return types
5. **Class Decorator** (Hard) - Add functionality to entire classes

### generators.py
1. **Fibonacci Generator** (Easy) - Generate Fibonacci sequence
2. **File Line Reader** (Medium) - Lazy file reading
3. **Infinite Counter** (Medium) - Generate infinite sequences
4. **Pipeline Generator** (Hard) - Chain generators together
5. **Custom Iterator Class** (Hard) - Implement iterator protocol

## Tips
- Generators save memory for large sequences
- Decorators should preserve function metadata
- Use functools.wraps in decorators
- Generators are great for lazy evaluation
- Context managers ensure proper resource cleanup
