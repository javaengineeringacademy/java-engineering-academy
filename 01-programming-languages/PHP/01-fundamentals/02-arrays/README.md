# PHP Arrays

## Overview
PHP arrays are ordered maps that can be indexed or associative.

## Indexed Arrays
```php
$colors = ["red", "green", "blue"];
```

## Associative Arrays
```php
$person = ["name" => "Alice", "age" => 30];
```

## Array Functions
```php
count($arr);
array_push($arr, $value);
array_pop($arr);
array_merge($arr1, $arr2);
```

## Multidimensional Arrays
```php
$matrix = [[1, 2], [3, 4]];
```
