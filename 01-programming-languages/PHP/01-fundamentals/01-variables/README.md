# PHP Variables

## Overview
PHP is dynamically typed with type juggling. Variables start with `$`.

## Variable Declaration
```php
$name = "Alice";
$age = 30;
$pi = 3.14;
$active = true;
```

## Type Juggling
```php
$var = "42";
$int = (int) $var;
```

## Type Checking
```php
var_dump($name);
gettype($name);
is_int($age);
```
