# PHP Design Patterns

PHP supports object-oriented patterns with features like interfaces, abstract classes, traits, and namespaces. Modern PHP (8.x) adds type declarations, enums, and match expressions.

## Core PHP Concepts

- **Interfaces and Abstract Classes**: Contract definitions and partial implementations
- **Traits**: Reusable code without inheritance limitations
- **Type Declarations**: Scalar types, return types, and union types
- **Namespaces**: Organizing code and avoiding naming conflicts
- **Composer**: Dependency management and autoloading

## Pattern Categories

### Creational Patterns
Singleton, Factory, Abstract Factory, Builder, Prototype -- using static methods, interfaces, and cloning.

### Structural Patterns
Adapter, Decorator, Facade, Proxy, Composite, Bridge, Flyweight -- using interfaces, traits, and composition.

### Behavioral Patterns
Observer, Strategy, Command, Iterator, State, Template, Chain of Responsibility, Mediator, Memento, Visitor, Interpreter -- using interfaces, closures, and callable types.

## Key PHP Features for Patterns

| Feature | Usage in Patterns |
|---|---|
| Interfaces | Contract enforcement |
| Traits | Mixin behavior |
| Closures | Strategy, Command |
| Clone | Prototype |
| match | State, Visitor |
| Enums | State machines |
