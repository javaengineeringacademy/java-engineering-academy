# Knowledge Atoms — C++ Language

## What are Knowledge Atoms?
The fundamental concepts shared across all C++ programs.

## Core Concepts

### 1. Compilation Model
C++ is compiled — source → object → executable.

### 2. Type System
Static, strongly typed with type inference (auto).

### 3. Memory Model
Stack vs Heap, RAII principle.

### 4. Object Model
Virtual tables, vptr, object layout.

### 5. Template Metaprogramming
Compile-time computation via templates.
