# Knowledge Atoms Exercises

## Exercise 1: Hello World
Create a basic C++ program that prints "Hello, World!" to the console.

**Requirements:**
- Use `#include <iostream>`
- Use `std::cout` for output
- Return 0 from main

## Exercise 2: Type Exploration
Write a program that demonstrates different data types in C++.

**Requirements:**
- Declare variables of types: int, float, double, char, bool
- Print their sizes using `sizeof()`
- Show type inference with `auto`

## Exercise 3: Memory Layout
Create a program that shows the difference between stack and heap memory.

**Requirements:**
- Create variables on the stack
- Use `new` to allocate on the heap
- Print memory addresses
- Properly delete heap memory
