# Knowledge Atoms Quiz

## Questions

### 1. What is the output of `sizeof(int)` on most modern systems?
A) 2 bytes
B) 4 bytes
C) 8 bytes
D) Platform dependent

### 2. Which keyword is used for type inference in C++?
A) `var`
B) `let`
C) `auto`
D) `dynamic`

### 3. What does RAII stand for?
A) Resource Acquisition Is Initialization
B) Runtime Allocation Is Immediate
C) Reference Association Is Instant
D) Random Access Is Immediate

### 4. Where are local variables typically stored?
A) Heap
B) Stack
C) Global memory
D) Registers only

### 5. What is the purpose of the `virtual` keyword?
A) To make functions inline
B) To enable dynamic dispatch
C) To create virtual memory
D) To make variables constant

### 6. What is the output of `sizeof(char)` in C++?
A) Always 1 byte
B) 2 bytes
C) 4 bytes
D) Platform dependent

### 7. What is the difference between `NULL` and `nullptr` in C++?
A) No difference
B) `nullptr` is type-safe, `NULL` may be defined as `0`
C) `NULL` is preferred in C++
D) `nullptr` is for integers only

### 8. Which C++ feature allows defining a function with the same name but different parameter lists?
A) Inheritance
B) Overloading
C) Polymorphism
D) Templates

### 9. What is the purpose of the `const` keyword?
A) To make a variable compile-time constant
B) To indicate read-only access
C) To optimize performance
D) To prevent function calls

### 10. What is the difference between `#include <file>` and `#include "file"`?
A) No difference
B) `<>` searches system paths, `""` searches local directory first
C) `""` is faster
D) `<>` is only for C headers

## Answers
1. B) 4 bytes
2. C) `auto`
3. A) Resource Acquisition Is Initialization
4. B) Stack
5. B) To enable dynamic dispatch
6. A) Always 1 byte
7. B) `nullptr` is type-safe, `NULL` may be defined as `0`
8. B) Overloading
9. B) To indicate read-only access
10. B) `<>` searches system paths, `""` searches local directory first
