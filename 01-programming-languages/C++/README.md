# C++ Programming Language

## Overview
C++ is a powerful systems programming language combining low-level access with high-level abstractions. Modern C++ (11/14/17/20) emphasizes safety and expressiveness.

## Topics Covered

### Fundamentals
- **Variables**: `int`, `double`, `string`, `auto`
- **Pointers**: Pointers, references, smart pointers
- **Arrays**: C arrays, `std::array`, `std::vector`
- **Strings**: `std::string`, `std::string_view`

### Object-Oriented Programming
- **Classes**: Class definitions, constructors, destructors
- **Inheritance**: Virtual functions, `override`
- **Polymorphism**: Virtual dispatch, pure virtual, vtable

### Advanced
- **Templates**: Function and class templates
- **Smart Pointers**: `unique_ptr`, `shared_ptr`, `weak_ptr`
- **Move Semantics**: `std::move`, rvalue references
- **Lambdas**: Lambda expressions, capture clauses
