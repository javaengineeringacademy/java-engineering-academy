# STL Exercises

## Exercise 1: Vector Operations
Perform common operations on vectors.

**Requirements:**
- Create a vector and add elements
- Remove elements by value and position
- Sort and reverse the vector
- Use algorithms: find, count, for_each

## Exercise 2: Map Usage
Implement a word frequency counter using maps.

**Requirements:**
- Read text input
- Count occurrences of each word
- Sort by frequency
- Display top 10 words

## Exercise 3: Custom Algorithm
Implement a custom algorithm using iterators.

**Requirements:**
- Create a function that finds all elements matching a predicate
- Use templates for generic implementation
- Test with different containers and predicates

## Exercise 4: Container Comparison
Compare performance of different containers.

**Requirements:**
- Test vector, list, and deque for:
  - Insertion at beginning
  - Insertion at end
  - Random access
  - Search operations
- Document performance characteristics
