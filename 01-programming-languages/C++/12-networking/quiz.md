# Networking Quiz

## Questions

### 1. What is the difference between TCP and UDP?
A) TCP is faster, UDP is reliable
B) TCP is reliable, UDP is faster
C) No difference
D) TCP is for web, UDP is for email

### 2. What is a socket?
A) A network cable
B) An endpoint for network communication
C) A network protocol
D) A network device

### 3. What is blocking I/O?
A) I/O that blocks other operations
B) I/O that waits for completion
C) I/O that runs in background
D) I/O that is encrypted

### 4. What is the purpose of HTTP status codes?
A) To indicate request success/failure
B) To encrypt data
C) To compress data
D) To cache data

### 5. What is a common use for UDP?
A) File transfer
B) Video streaming
C) Email
D) Web browsing

### 6. What is the difference between synchronous and asynchronous I/O?
A) No difference
B) Synchronous blocks until complete; asynchronous returns immediately and uses callbacks/futures
C) Asynchronous is slower
D) Synchronous is deprecated

### 7. What is a connection pool?
A) A pool of connected users
B) A cache of reusable database/network connections
C) A type of network switch
D) A wireless access point

### 8. What is the difference between `recv` and `read` for sockets?
A) No difference
B) `recv` can handle flags and socket-specific behavior; `read` is generic
C) `read` is faster
D) `recv` is deprecated

### 9. What is a WebSocket?
A) A web server
B) A protocol for full-duplex communication over a single TCP connection
C) A JavaScript library
D) A database protocol

### 10. What is SSL/TLS used for in networking?
A) Data compression
B) Encrypting communication between client and server
C) Load balancing
D) Caching responses

## Answers
1. B) TCP is reliable, UDP is faster
2. B) An endpoint for network communication
3. B) I/O that waits for completion
4. A) To indicate request success/failure
5. B) Video streaming
6. B) Synchronous blocks until complete; asynchronous returns immediately and uses callbacks/futures
7. B) A cache of reusable database/network connections
8. B) `recv` can handle flags and socket-specific behavior; `read` is generic
9. B) A protocol for full-duplex communication over a single TCP connection
10. B) Encrypting communication between client and server
