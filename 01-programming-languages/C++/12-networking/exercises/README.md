# Networking Exercises

## Exercise 1: TCP Client/Server
Implement a simple TCP client and server.

**Requirements:**
- Server listens on a port
- Client connects and sends messages
- Server echoes messages back
- Handle multiple clients

## Exercise 2: HTTP Client
Create an HTTP client using libcurl.

**Requirements:**
- Make GET requests
- Make POST requests with data
- Handle responses and errors
- Parse JSON responses

## Exercise 3: Async Server
Implement an asynchronous server.

**Requirements:**
- Use Boost.Asio
- Handle multiple connections
- Implement echo service
- Measure performance

## Exercise 4: WebSocket Client
Implement a WebSocket client.

**Requirements:**
- Connect to WebSocket server
- Send and receive messages
- Handle connection close
- Implement ping/pong
