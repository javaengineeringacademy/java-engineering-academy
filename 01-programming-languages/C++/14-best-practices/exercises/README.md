# Best Practices Exercises

## Exercise 1: Code Review
Review and improve existing code.

**Requirements:**
- Analyze code for style issues
- Identify missing const correctness
- Improve error handling
- Refactor for readability

## Exercise 2: Refactoring
Refactor a complex function.

**Requirements:**
- Break down large functions
- Extract helper functions
- Improve naming
- Add proper documentation

## Exercise 3: Const Correctness
Apply const correctness throughout a project.

**Requirements:**
- Mark methods as const
- Use const references for parameters
- Use const iterators
- Test compilation

## Exercise 4: Error Handling
Implement proper error handling.

**Requirements:**
- Replace error codes with exceptions
- Add proper cleanup in catch blocks
- Use RAII for resource management
- Write error handling tests
