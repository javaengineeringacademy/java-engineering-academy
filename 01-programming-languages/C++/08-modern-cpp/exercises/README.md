# Modern C++ Exercises

## Exercise 1: Lambda Functions
Implement various lambda expressions.

**Requirements:**
- Create simple lambda
- Use captures (by value, by reference)
- Create generic lambda
- Use lambda with STL algorithms

## Exercise 2: Move Semantics
Implement move constructor and move assignment.

**Requirements:**
- Create a resource-managing class
- Implement move constructor
- Implement move assignment operator
- Test with vectors of objects

## Exercise 3: Structured Bindings
Use structured bindings with different data structures.

**Requirements:**
- Unpack pairs and tuples
- Use with maps
- Use with custom structs
- Compare with traditional methods

## Exercise 4: Concepts (C++20)
Implement concepts for template constraints.

**Requirements:**
- Create basic concepts (EqualityComparable, LessThanComparable)
- Use concepts with function templates
- Create composite concepts
- Test with different types
