# Modern C++ Quiz

## Questions

### 1. What is the output of `auto x = 42;`?
A) `int x = 42;`
B) `auto x = 42;`
C) `x` is type `auto`
D) Error

### 2. What does `std::move()` do?
A) Actually moves data
B) Casts to rvalue reference
C) Deletes the source
D) Copies the data

### 3. What is a capture list in a lambda?
A) List of variables to capture from enclosing scope
B) List of function parameters
C) List of local variables
D) List of global variables

### 4. What is structured binding (C++17)?
A) Binding two variables together
B) Unpacking multiple return values
C) Creating aliases
D) Template specialization

### 5. What is the purpose of concepts (C++20)?
A) To replace templates
B) To constrain template parameters
C) To improve runtime performance
D) To simplify syntax

### 6. What is `std::optional` (C++17)?
A) A type that may or may not hold a value
B) A pointer that may be null
C) A container for optional data
D) A function with optional parameters

### 7. What is `std::variant` (C++17)?
A) A variable that can change type
B) A type-safe union
C) A template with variants
D) An optional parameter type

### 8. What is a range-based for loop?
A) A for loop that iterates over a range of numbers
B) A for loop that iterates over elements in a container using begin/end
C) A for loop with a range check
D) A loop that runs a range of times

### 9. What is `constexpr` used for?
A) To make variables mutable
B) To evaluate expressions at compile time
C) To define runtime constants
D) To replace `const`

### 10. What is `std::string_view` (C++17)?
A) A mutable string
B) A non-owning reference to a string-like object
C) A string that views other strings
D) A deprecated string type

## Answers
1. A) `int x = 42;`
2. B) Casts to rvalue reference
3. A) List of variables to capture from enclosing scope
4. B) Unpacking multiple return values
5. B) To constrain template parameters
6. A) A type that may or may not hold a value
7. B) A type-safe union
8. B) A for loop that iterates over elements in a container using begin/end
9. B) To evaluate expressions at compile time
10. B) A non-owning reference to a string-like object
