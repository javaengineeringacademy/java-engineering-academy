# Fundamentals Exercises

## Exercise 1: Calculator
Create a simple calculator that performs addition, subtraction, multiplication, and division.

**Requirements:**
- Use functions for each operation
- Handle division by zero
- Use switch-case for operation selection

## Exercise 2: Array Operations
Write functions to perform common array operations.

**Requirements:**
- Find maximum and minimum values
- Calculate average
- Reverse the array
- Search for an element

## Exercise 3: String Manipulation
Create a program that manipulates strings.

**Requirements:**
- Count vowels and consonants
- Reverse a string
- Check if palindrome
- Convert to uppercase/lowercase

## Exercise 4: Pointer Practice
Demonstrate pointer usage with arrays.

**Requirements:**
- Use pointers to traverse arrays
- Swap two values using pointers
- Demonstrate pointer arithmetic
