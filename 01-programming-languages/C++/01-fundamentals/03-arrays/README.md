# C++ Arrays

## Overview
C++ offers C-style arrays, `std::array`, and `std::vector`.

## C-style Array
```cpp
int arr[5] = {1, 2, 3, 4, 5};
```

## std::array
```cpp
#include <array>
std::array<int, 5> arr = {1, 2, 3, 4, 5};
```

## std::vector
```cpp
#include <vector>
std::vector<int> vec = {1, 2, 3};
vec.push_back(4);
```
