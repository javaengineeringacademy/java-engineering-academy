# Fundamentals Quiz

## Questions

### 1. What is the correct way to declare a constant in C++?
A) `constant int MAX = 100;`
B) `const int MAX = 100;`
C) `#define MAX 100`
D) Both B and C

### 2. What is the output of `sizeof(char)`?
A) 1 byte
B) 2 bytes
C) 4 bytes
D) Platform dependent

### 3. Which loop is guaranteed to execute at least once?
A) `for` loop
B) `while` loop
C) `do-while` loop
D) None

### 4. What is the difference between `NULL` and `nullptr`?
A) No difference
B) `nullptr` is type-safe, `NULL` is not
C) `NULL` is type-safe, `nullptr` is not
D) `nullptr` is for pointers, `NULL` is for integers

### 5. What is function overloading?
A) Multiple functions with the same name but different parameters
B) Multiple functions with different names
C) Calling a function multiple times
D) A function that calls itself

### 6. What is the output of the following code?
```cpp
int x = 5;
int y = x++;
```
A) x=5, y=5
B) x=6, y=5
C) x=6, y=6
D) x=5, y=6

### 7. What is the difference between `++i` and `i++`?
A) No difference
B) `++i` increments and returns new value; `i++` returns old value then increments
C) `i++` is faster
D) `++i` is deprecated

### 8. What happens when you divide by zero with integers in C++?
A) Returns infinity
B) Undefined behavior
C) Returns 0
D) Throws an exception

### 9. What is the purpose of `using namespace std;`?
A) It imports all standard library names into the current scope
B) It creates a new namespace
C) It defines the standard library
D) It optimizes standard library calls

### 10. What is the difference between `size_t` and `int`?
A) No difference
B) `size_t` is unsigned and guaranteed to hold the largest possible object size
C) `int` is always larger
D) `size_t` is deprecated

## Answers
1. D) Both B and C
2. A) 1 byte
3. C) `do-while` loop
4. B) `nullptr` is type-safe, `NULL` is not
5. A) Multiple functions with the same name but different parameters
6. B) x=6, y=5
7. B) `++i` increments and returns new value; `i++` returns old value then increments
8. B) Undefined behavior
9. A) It imports all standard library names into the current scope
10. B) `size_t` is unsigned and guaranteed to hold the largest possible object size
