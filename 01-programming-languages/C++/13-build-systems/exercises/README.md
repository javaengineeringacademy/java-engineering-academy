# Build Systems Exercises

## Exercise 1: CMake Project
Create a CMake project with multiple targets.

**Requirements:**
- Create library and executable targets
- Use proper directory structure
- Add compiler flags
- Implement install targets

## Exercise 2: Makefile
Write a Makefile for a C++ project.

**Requirements:**
- Compile multiple source files
- Handle dependencies
- Implement clean target
- Add debug and release builds

## Exercise 3: Package Management
Use a package manager for dependencies.

**Requirements:**
- Install a library using vcpkg or Conan
- Link library in CMake
- Test library functionality
- Document dependency management

## Exercise 4: Cross-Compilation
Set up cross-compilation for different platform.

**Requirements:**
- Create toolchain file
- Configure CMake for cross-compilation
- Build for target platform
- Test on target platform
