# Build Systems Quiz

## Questions

### 1. What is CMake?
A) A compiler
B) A build system generator
C) A debugger
D) An IDE

### 2. What is the purpose of a Makefile?
A) To write code
B) To automate build process
C) To debug code
D) To test code

### 3. What is cross-compilation?
A) Compiling for multiple platforms
B) Compiling on one platform for another
C) Compiling with multiple compilers
D) Compiling multiple projects

### 4. What is a package manager?
A) A tool for installing libraries
B) A tool for writing code
C) A tool for debugging
D) A tool for testing

### 5. What is the benefit of out-of-source builds?
A) Faster compilation
B) Keeps source directory clean
C) Better code organization
D) All of the above

### 6. What is the difference between `add_executable` and `add_library` in CMake?
A) No difference
B) `add_executable` creates a program; `add_library` creates a static/dynamic library
C) `add_library` is faster
D) `add_executable` is deprecated

### 7. What is a build configuration?
A) A source code file
B) A set of compiler and linker options for a specific build type (Debug, Release, etc.)
C) A type of CMake project
D) A source file organization method

### 8. What is Ninja in the context of build systems?
A) A programming language
B) A fast, small build system used as a backend for CMake
C) A debugger
D) A package manager

### 9. What is `target_link_libraries` used for in CMake?
A) Linking source files
B) Specifying libraries that a target depends on
C) Creating library targets
D) Defining build rules

### 10. What is the purpose of `install` targets in CMake?
A) Compiling code
B) Copying built artifacts to a destination directory
C) Running tests
D) Debugging code

## Answers
1. B) A build system generator
2. B) To automate build process
3. B) Compiling on one platform for another
4. A) A tool for installing libraries
5. D) All of the above
6. B) `add_executable` creates a program; `add_library` creates a static/dynamic library
7. B) A set of compiler and linker options for a specific build type (Debug, Release, etc.)
8. B) A fast, small build system used as a backend for CMake
9. B) Specifying libraries that a target depends on
10. B) Copying built artifacts to a destination directory
