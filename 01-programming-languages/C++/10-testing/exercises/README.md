# Testing Exercises

## Exercise 1: Unit Testing
Write unit tests for a calculator class.

**Requirements:**
- Create Calculator class with add, subtract, multiply, divide
- Write tests for each operation
- Test edge cases (division by zero, overflow)
- Use Google Test framework

## Exercise 2: Test Fixtures
Implement test fixtures for a bank account.

**Requirements:**
- Create BankAccount class
- Use test fixture for setup/teardown
- Test deposit, withdraw, balance
- Test with different account types

## Exercise 3: Mocking
Mock an external dependency.

**Requirements:**
- Create interface for database
- Implement mock class
- Write tests using mock
- Verify mock interactions

## Exercise 4: Test Coverage
Achieve high test coverage for a module.

**Requirements:**
- Measure current coverage
- Identify uncovered paths
- Write tests to increase coverage
- Document coverage results
