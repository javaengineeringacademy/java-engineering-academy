# Testing Quiz

## Questions

### 1. What is a unit test?
A) Testing the entire system
B) Testing individual functions or methods
C) Testing performance
D) Testing user interface

### 2. What is the purpose of test fixtures?
A) To create test data
B) To provide setup and teardown for tests
C) To run tests faster
D) To generate test reports

### 3. What is mocking?
A) Creating fake implementations of dependencies
B) Making fun of bad code
C) Creating real implementations
D) Testing without dependencies

### 4. What is TDD?
A) Test-Driven Development
B) Test Document Design
C) Total Test Coverage
D) Technical Test Design

### 5. What is the benefit of high test coverage?
A) No bugs in code
B) Confidence in code changes
C) Faster execution
D) Less documentation needed

### 6. What is a test double?
A) Running tests twice
B) A generic term for mocks, stubs, fakes, and spies
C) A type of test framework
D) A test that runs twice as fast

### 7. What is the difference between a mock and a stub?
A) No difference
B) Mock verifies interactions; stub provides canned responses
C) Stub is more flexible
D) Mock is deprecated

### 8. What is property-based testing?
A) Testing object properties
B) Testing functions with randomly generated inputs to verify properties/invariants
C) Testing class members
D) Testing memory properties

### 9. What is the purpose of `ASSERT_*` macros in Google Test?
A) To print output
B) To check conditions and continue on failure
C) To abort the test on failure
D) To skip the test

### 10. What is continuous testing?
A) Running tests manually
B) Automatically running tests as part of the development pipeline
C) Testing for a long time
D) Testing without stopping

## Answers
1. B) Testing individual functions or methods
2. B) To provide setup and teardown for tests
3. A) Creating fake implementations of dependencies
4. A) Test-Driven Development
5. B) Confidence in code changes
6. B) A generic term for mocks, stubs, fakes, and spies
7. B) Mock verifies interactions; stub provides canned responses
8. B) Testing functions with randomly generated inputs to verify properties/invariants
9. C) To abort the test on failure
10. B) Automatically running tests as part of the development pipeline
