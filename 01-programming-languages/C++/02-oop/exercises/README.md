# OOP Exercises

## Exercise 1: Bank Account System
Create a bank account system with classes.

**Requirements:**
- Create a `BankAccount` class with deposit, withdraw, and balance methods
- Create a `SavingsAccount` class that inherits from `BankAccount`
- Add interest calculation to `SavingsAccount`
- Use proper encapsulation

## Exercise 2: Shape Hierarchy
Design a shape hierarchy with polymorphism.

**Requirements:**
- Create abstract `Shape` class with `area()` and `perimeter()` methods
- Implement `Circle`, `Rectangle`, and `Triangle` classes
- Use virtual functions for polymorphic behavior
- Add a function to calculate total area of shapes

## Exercise 3: Employee Management
Build an employee management system.

**Requirements:**
- Create `Employee` base class
- Derive `Manager`, `Engineer`, and `Intern` classes
- Implement salary calculation based on role
- Use polymorphism to display employee information

## Exercise 4: Smart Pointers with OOP
Implement a simple object hierarchy with smart pointers.

**Requirements:**
- Use `std::unique_ptr` for exclusive ownership
- Use `std::shared_ptr` for shared ownership
- Demonstrate proper memory management
