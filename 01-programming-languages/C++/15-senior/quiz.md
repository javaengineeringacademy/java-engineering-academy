# Senior Level Quiz

## Questions

### 1. What is the primary role of a senior developer?
A) Write more code
B) Lead technical decisions
C) Fix all bugs
D) Work longer hours

### 2. What is technical debt?
A) Money spent on technology
B) Future cost of quick fixes
C) Technical complexity
D) Code that is hard to understand

### 3. What is the importance of documentation?
A) It's required by law
B) It helps others understand the system
C) It makes code run faster
D) It's not important

### 4. What is a code review?
A) Checking code for syntax errors
B) Systematic examination of code by peers
C) Running automated tests
D) Writing documentation

### 5. What is the goal of architecture?
A) Make code complex
B) Create systems that scale and are maintainable
C) Use latest technologies
D) Impress other developers

### 6. What is the difference between a monolith and microservices?
A) No difference
B) Monolith is a single deployable unit; microservices are independently deployable services
C) Microservices are always better
D) Monoliths are deprecated

### 7. What is the CAP theorem?
A) A theorem about algorithm complexity
B) A distributed system can provide at most two of: Consistency, Availability, Partition tolerance
C) A theorem about cache performance
D) A theorem about concurrency

### 8. What is a design review?
A) Reviewing code for bugs
B) Evaluating architectural and design decisions before implementation
C) Reviewing user interfaces
D) Reviewing documentation

### 9. What is the purpose of API versioning?
A) To increase code complexity
B) To maintain backward compatibility while allowing evolution
C) To track API usage
D) To enforce licensing

### 10. What is the SOLID principle?
A) A set of five OOP design principles for maintainable code
B) A testing methodology
C) A performance optimization technique
D) A security framework

## Answers
1. B) Lead technical decisions
2. B) Future cost of quick fixes
3. B) It helps others understand the system
4. B) Systematic examination of code by peers
5. B) Create systems that scale and are maintainable
6. B) Monolith is a single deployable unit; microservices are independently deployable services
7. B) A distributed system can provide at most two of: Consistency, Availability, Partition tolerance
8. B) Evaluating architectural and design decisions before implementation
9. B) To maintain backward compatibility while allowing evolution
10. A) A set of five OOP design principles for maintainable code
