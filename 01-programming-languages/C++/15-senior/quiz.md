# Senior Level Quiz

## Questions

### 1. What is the primary role of a senior developer?
A) Write more code  
B) Lead technical decisions  
C) Fix all bugs  
D) Work longer hours

### 2. What is technical debt?
A) Money spent on technology  
B) Future cost of quick fixes  
C) Technical complexity  
D) Code that is hard to understand

### 3. What is the importance of documentation?
A) It's required by law  
B) It helps others understand the system  
C) It makes code run faster  
D) It's not important

### 4. What is a code review?
A) Checking code for syntax errors  
B) Systematic examination of code by peers  
C) Running automated tests  
D) Writing documentation

### 5. What is the goal of architecture?
A) Make code complex  
B) Create systems that scale and are maintainable  
C) Use latest technologies  
D) Impress other developers

## Answers
1. B) Lead technical decisions
2. B) Future cost of quick fixes
3. B) It helps others understand the system
4. B) Systematic examination of code by peers
5. B) Create systems that scale and are maintainable
