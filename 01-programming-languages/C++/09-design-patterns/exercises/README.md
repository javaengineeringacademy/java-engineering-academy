# Design Patterns Exercises

## Exercise 1: Singleton Implementation
Implement a thread-safe singleton.

**Requirements:**
- Use double-checked locking
- Implement lazy initialization
- Prevent copy and assignment
- Test thread safety

## Exercise 2: Factory Pattern
Create a factory for different shapes.

**Requirements:**
- Create Shape interface
- Implement Circle, Rectangle, Triangle
- Create ShapeFactory
- Use smart pointers for memory management

## Exercise 3: Observer Pattern
Implement an event system.

**Requirements:**
- Create Subject and Observer interfaces
- Implement EventManager
- Create concrete observers
- Demonstrate event notification

## Exercise 4: Strategy Pattern
Implement different sorting strategies.

**Requirements:**
- Create SortStrategy interface
- Implement BubbleSort, QuickSort, MergeSort
- Create Sorter context
- Compare performance
