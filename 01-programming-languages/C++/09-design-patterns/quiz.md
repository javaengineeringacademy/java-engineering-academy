# Design Patterns Quiz

## Questions

### 1. What is the Singleton pattern?
A) Creating multiple instances
B) Ensuring a class has only one instance
C) Destroying instances
D) Copying instances

### 2. What is the Factory pattern used for?
A) Creating objects without specifying exact class
B) Destroying objects
C) Modifying objects
D) Copying objects

### 3. What is the Observer pattern?
A) Observing memory usage
B) One-to-many dependency where changes notify dependents
C) Observing CPU usage
D) Observing network traffic

### 4. What is the Strategy pattern?
A) Game strategies
B) Algorithm selection at runtime
C) Marketing strategies
D) Security strategies

### 5. When should you use design patterns?
A) Always, for every problem
B) Only when they solve a specific problem
C) Never, they're outdated
D) Only in large projects

### 6. What is the Decorator pattern?
A) Adding behavior to objects dynamically without modifying their class
B) Decorating code for readability
C) Adding comments to code
D) Creating abstract classes

### 7. What is the difference between Factory and Abstract Factory?
A) No difference
B) Factory creates one product type; Abstract Factory creates families of related products
C) Abstract Factory is simpler
D) Factory is deprecated

### 8. What is the Builder pattern used for?
A) Building software
B) Separating construction of complex objects from representation
C) Building hardware
D) Creating simple objects

### 9. What is the Adapter pattern?
A) Adapting code for performance
B) Converting one interface to another that clients expect
C) Adapting to hardware
D) Converting data types

### 10. What is an anti-pattern?
A) A design pattern used in reverse
B) A common but ineffective or counterproductive solution to a problem
C) A deprecated pattern
D) A pattern for testing

## Answers
1. B) Ensuring a class has only one instance
2. A) Creating objects without specifying exact class
3. B) One-to-many dependency where changes notify dependents
4. B) Algorithm selection at runtime
5. B) Only when they solve a specific problem
6. A) Adding behavior to objects dynamically without modifying their class
7. B) Factory creates one product type; Abstract Factory creates families of related products
8. B) Separating construction of complex objects from representation
9. B) Converting one interface to another that clients expect
10. B) A common but ineffective or counterproductive solution to a problem
