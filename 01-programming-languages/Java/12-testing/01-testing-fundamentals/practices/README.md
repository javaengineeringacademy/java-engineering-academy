# Testing Fundamentals - Practice Exercises

Complete the following exercises to reinforce testing fundamentals.

## Exercises

| File | Difficulty | Topic |
|------|------------|-------|
| `Exercise1CalculatorTest.java` | Easy | Basic assertions and AAA pattern |
| `Exercise2StringValidatorTest.java` | Medium | Edge cases and exception testing |
| `Exercise3ShoppingCartTest.java` | Hard | Complex test scenarios with nested tests |

## Instructions

1. Read the exercise file and understand the class under test
2. Write the test methods following AAA pattern
3. Run tests to verify they pass
4. Check solutions only after attempting the exercise
