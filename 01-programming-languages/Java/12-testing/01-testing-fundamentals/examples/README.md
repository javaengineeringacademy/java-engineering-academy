# Testing Fundamentals - Examples

This directory contains example code demonstrating core testing concepts.

## Files

| File | Description |
|------|-------------|
| `TestingBasics.java` | Unit tests, edge cases, AAA pattern |

## Key Concepts Demonstrated

1. **AAA Pattern**: Arrange setup, Act execute, Assert verify
2. **Edge Cases**: Null inputs, boundary values, invalid states
3. **Test Naming**: Descriptive `@DisplayName` annotations
4. **Assertion Variety**: assertEquals, assertTrue, assertThrows, assertAll
5. **Test Organization**: Grouping related tests with clear naming
