# BDD Testing Quiz

## Question 1
What language does Cucumber use?

- A) Java
- B) Gherkin
- C) Python
- D) XML

**Answer: B**
**Explanation:** Cucumber uses Gherkin, a natural language syntax for writing scenarios.

---

## Question 2
What is a feature file?

- A) A Java class
- B) A file with .feature extension containing Gherkin scenarios
- C) A configuration file
- D) A report file

**Answer: B**
**Explanation:** Feature files use .feature extension and contain Gherkin scenarios.

---

## Question 3
What keyword starts a scenario?

- A) Test
- B) Scenario
- C) Method
- D) Function

**Answer: B**
**Explanation:** The Scenario keyword starts a new test scenario in Gherkin.

---

## Question 4
What is a step definition?

- A) A feature file
- B) A Java method implementing a Gherkin step
- C) A test configuration
- D) A report generator

**Answer: B**
**Explanation:** Step definitions are Java methods that execute the steps in scenarios.

---

## Question 5
What does Background do?

- A) Runs before all scenarios
- B) Runs before each scenario
- C) Runs after all scenarios
- D) Runs after each scenario

**Answer: B**
**Explanation:** Background steps run before each scenario in a feature.

---

## Question 6
What is a Scenario Outline?

- A) A scenario template with examples
- B) A detailed scenario
- C) A background scenario
- D) A tag

**Answer: A**
- **Explanation:** Scenario Outline allows data-driven testing with Examples tables.

---

## Question 7
What are tags used for?

- A) Grouping scenarios
- B) Filtering test execution
- C) Both A and B
- D) Neither

**Answer: C**
**Explanation:** Tags group scenarios and can filter which tests to run.

---

## Question 8
What is a data table in Gherkin?

- A) A table in the database
- B) Tabular data passed to step definitions
- C) A report format
- D) A configuration table

**Answer: B**
**Explanation:** Data tables provide tabular data to step definitions.

---

## Question 9
What is the Given-When-Then pattern?

- A) Test setup, execution, verification
- B) Arrange, Act, Assert
- C) Both A and B
- D) Neither

**Answer: C**
**Explanation:** Given-When-Then is the BDD equivalent of Arrange-Act-Assert.

---

## Question 10
What does Cucumber generate?

- A) Source code
- B) Test reports in HTML/JSON
- C) Configuration files
- D) Documentation only

**Answer: B**
**Explanation:** Cucumber generates HTML and JSON reports showing scenario results.
