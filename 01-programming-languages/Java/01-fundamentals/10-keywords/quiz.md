# Keywords - Quiz

## Questions

### Q1: Which keyword declares a class?
- A) struct
- B) class
- C) type
- D) object

### Q2: What does `final` mean?
- A) Cannot be changed (constant)
- B) Must be initialized
- C) Public access
- D) Static method

### Q3: Which keyword creates an object?
- A) new
- B) create
- C) instance
- D) make

### Q4: What does `this` refer to?
- A) The parent class
- B) The current instance
- C) The static context
- D) The method

### Q5: What does `super` do?
- A) Calls the parent class constructor/method
- B) Creates a new object
- C) Defines a subclass
- D) Imports a package

### Q6: Which keyword is used for exception handling?
- A) try-catch-finally
- B) handle-throw
- C) error-exception
- D) catch-throw

### Q7: What does `static` mean?
- A) Cannot be modified
- B) Belongs to the class, not instances
- C) Is thread-safe
- D) Is public

### Q8: Which keyword is used to inherit a class?
- A) implements
- B) extends
- C) inherits
- D) derives

### Q9: What does `abstract` mean?
- A) A concrete class
- B) Cannot be instantiated; may have abstract methods
- C) A final class
- D) A static class

### Q10: What is `instanceof` used for?
- A) Creating instances
- B) Checking if an object is an instance of a type
- C) Casting objects
- D) Importing classes

## Answers

1. **B** - `class` is used to declare a class
2. **A** - `final` prevents reassignment
3. **A** - `new` allocates and initializes a new object
4. **B** - `this` refers to the current object instance
5. **A** - `super` accesses parent class members
6. **A** - `try-catch-finally` handles exceptions
7. **B** - `static` members belong to the class, not any instance
8. **B** - `extends` is used for class inheritance
9. **B** - `abstract` classes cannot be instantiated directly
10. **B** - `instanceof` checks type at runtime
