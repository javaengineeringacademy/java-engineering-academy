# Keywords - Practices

## Practice 1: Final Class
Create a final class that cannot be extended. Show the compilation error when trying to extend it.

## Practice 2: Static Factory Method
Use the `static` keyword to create a factory method that returns instances of a class.

## Practice 3: This vs Super
Create a class hierarchy demonstrating `this` and `super` usage in constructors.

## Practice 4: Abstract Class
Create an abstract class with abstract and concrete methods. Implement it in a subclass.

## Practice 5: Instanceof Chain
Use `instanceof` to check multiple types in a method using pattern matching.

## Practice 6: Try-With-Resources
Demonstrate `try-with-resources` for automatic resource management.
