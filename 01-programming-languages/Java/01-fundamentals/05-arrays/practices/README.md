# Arrays - Practices

## Practice 1: Find Max and Min
Write a method that finds the maximum and minimum values in an integer array without using Arrays.sort.

## Practice 2: Reverse Array
Reverse the elements of an array in-place.

## Practice 3: Array Intersection
Given two arrays, return a new array containing only the common elements.

## Practice 4: Matrix Multiplication
Implement a method that multiplies two 2D integer arrays (matrices).

## Practice 5: Flatten 2D Array
Write a method that flattens a 2D array into a 1D array.

## Practice 6: Remove Duplicates
Remove duplicate elements from a sorted array in-place and return the new length.
