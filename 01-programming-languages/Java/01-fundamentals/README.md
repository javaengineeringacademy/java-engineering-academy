# Java Fundamentals

## Overview
Java fundamentals cover the building blocks of the Java programming language — variables, data types, control flow, operators, methods, and arrays.

## What You'll Learn
- Variables and data types (int, double, boolean, char, String)
- Operators (arithmetic, relational, logical, bitwise)
- Control flow (if/else, switch, for, while, do-while)
- Methods (declaration, parameters, return types, overloading)
- Arrays (1D, 2D, Array class, common operations)
- String basics (String, StringBuilder, StringBuffer)

## Prerequisites
None — this is where you start.
