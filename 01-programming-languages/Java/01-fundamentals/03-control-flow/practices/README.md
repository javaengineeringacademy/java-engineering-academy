# Control Flow - Practices

## Practice 1: FizzBuzz
Write a program that prints numbers 1-100, but prints "Fizz" for multiples of 3, "Buzz" for multiples of 5, and "FizzBuzz" for both.

## Practice 2: Star Triangle
Use nested loops to print a right triangle of stars:
```
*
**
***
****
*****
```

## Practice 3: Switch Calculator
Build a simple calculator that takes two numbers and an operator (+, -, *, /) using a switch expression.

## Practice 4: Labeled Break Demo
Use a labeled break to exit a nested loop when a target value is found in a 2D array.

## Practice 5: Collatz Sequence
Implement the Collatz conjecture: start with any positive integer, if even divide by 2, if odd multiply by 3 and add 1. Print the sequence until reaching 1.

## Practice 6: Prime Checker Loop
Write a method that checks if a number is prime using a for loop with early exit via break.
