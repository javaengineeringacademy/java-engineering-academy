# Java Fundamentals Solutions

Complete solutions for all exercises in the practices folder.

---

## Solutions Overview

| Exercise | File | Description |
|----------|------|-------------|
| Variables | `VariableSolutions.java` | Primitive types, casting, naming |
| Operators | `OperatorSolutions.java` | Arithmetic, bitwise, logical |
| Control Flow | `ControlFlowSolutions.java` | FizzBuzz, primes, patterns |
| Methods | `MethodSolutions.java` | Overloading, recursion, varargs |
| Arrays | `ArraySolutions.java` | Matrix, rotation, missing number |
| Strings | `StringSolutions.java` | Reverse, anagram, compression |

## How to Use

```bash
# Navigate to the solutions folder
cd solutions/

# Compile and run any solution
javac VariableSolutions.java
java VariableSolutions
```

## Learning Approach

1. **Try first**: Attempt each exercise before looking at the solution
2. **Compare**: After solving, compare your approach with the solution
3. **Understand**: Read the comments explaining why the solution works
4. **Practice**: Modify the solution to handle additional edge cases

## Solution Structure

Each solution file contains:
- Method implementations for all exercises
- `main()` method with test cases
- Expected output for verification
- Comments explaining the approach

## Key Concepts Practiced

- Primitive type operations and casting
- Arithmetic and bitwise operators
- Conditional logic and loops
- Method design and overloading
- Array manipulation algorithms
- String processing techniques
