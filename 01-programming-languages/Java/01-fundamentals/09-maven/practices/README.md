# Maven - Practices

## Practice 1: Create a Project
Use `mvn archetype:generate` to create a new Maven project with proper structure.

## Practice 2: Add Dependencies
Add Gson and JUnit dependencies to a pom.xml and verify with `mvn dependency:tree`.

## Practice 3: Multi-Module Build
Create a multi-module Maven project with a parent POM and two child modules.

## Practice 4: Custom Plugin
Configure the Maven Compiler plugin to use Java 21 and UTF-8 encoding.

## Practice 5: Build Profiles
Create Maven profiles for development and production configurations.

## Practice 6: Shade Plugin
Use the Maven Shade plugin to create a fat JAR with all dependencies.
