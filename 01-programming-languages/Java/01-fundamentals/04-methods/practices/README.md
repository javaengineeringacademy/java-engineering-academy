# Methods - Practices

## Practice 1: Method Overloading
Create overloaded `display` methods that accept int, String, and boolean parameters, each printing a formatted message.

## Practice 2: Recursive Power
Write a recursive method `power(base, exp)` that computes base^exp without using Math.pow.

## Practice 3: Varargs Average
Create a method `average(double... values)` that returns the average of all passed values.

## Practice 4: Palindrome Checker
Write a recursive method that checks if a string is a palindrome.

## Practice 5: Method Chaining
Design a class with methods that return `this` to enable fluent method chaining.
