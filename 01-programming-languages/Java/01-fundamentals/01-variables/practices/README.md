# Variables - Practices

## Practice 1: Temperature Converter
Create variables to store temperatures in Celsius and Fahrenheit. Convert between them and print the results.

## Practice 2: Variable Declarations
Declare variables of every primitive type with meaningful names and initial values. Print each variable with its type.

## Practice 3: Type Overflow Demo
Demonstrate overflow by assigning values beyond the range of `byte`, `short`, and `int`. Document what happens.

## Practice 4: Final Variable Calculator
Use `final` variables for mathematical constants (PI, E, gravity). Calculate and print the area of a circle.

## Practice 5: Scope Investigation
Create nested blocks and attempt to access variables from outer scopes. Document which access patterns compile and which don't.

## Practice 6: var Inference
Use `var` for local variable declarations with different initializer types. Verify the inferred types using reflection.

## Practice 7: Naming Conventions
Create variables following Java naming conventions: camelCase for variables, UPPER_SNAKE_CASE for constants, PascalCase for classes.
