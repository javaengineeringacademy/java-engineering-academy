# Operators - Practices

## Practice 1: Bitmask Flags
Use bitwise operators to create a permission system with READ, WRITE, and EXECUTE flags. Set, clear, and toggle permissions.

## Practice 2: Swap Without Temp
Swap two integer variables without using a temporary variable using XOR or arithmetic operators.

## Practice 3: Operator Precedence
Write an expression using 5+ different operators. Predict the result without running, then verify.

## Practice 4: Short-Circuit Demo
Create a method that returns false and has a side effect. Use it in short-circuit expressions to demonstrate when the side effect does/doesn't occur.

## Practice 5: Bitwise Division
Implement integer division by 2 using only bitwise shift operators.

## Practice 6: Ternary Calculator
Use nested ternary operators to calculate shipping cost based on weight thresholds.
