# Wrapper Classes - Practices

## Practice 1: Safe Null Handling
Create a method that safely converts a String to Integer, returning a default value for null or invalid input.

## Practice 2: Autoboxing Demo
Demonstrate autoboxing/unboxing in arithmetic expressions and show where implicit conversion happens.

## Practice 3: Cache Comparison
Compare `==` vs `.equals()` for Integer values across the cache boundary (127 vs 128).

## Practice 4: Wrapper Array to Primitive
Convert a `List<Integer>` to an `int[]` using autoboxing.

## Practice 5: Bit Manipulation
Use Integer methods to check if a number is a power of 2 using bit counting.
