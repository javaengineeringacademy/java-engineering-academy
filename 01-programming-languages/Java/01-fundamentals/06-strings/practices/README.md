# Strings - Practices

## Practice 1: Reverse a String
Write a method to reverse a string using both StringBuilder and manual char swapping.

## Practice 2: Palindrome Checker
Check if a given string is a palindrome (ignore case and non-alphanumeric characters).

## Practice 3: Word Counter
Count the number of words in a sentence.

## Practice 4: Character Frequency
Count the frequency of each character in a string using a HashMap.

## Practice 5: String Compression
Implement basic string compression: "aabcccccaaa" → "a2b1c5a3".

## Practice 6: Anagram Checker
Determine if two strings are anagrams of each other.
