# Project Structure - Practices

## Practice 1: Create a Maven Project
Create a new Maven project from scratch with the standard directory layout and a basic pom.xml.

## Practice 2: Add a Dependency
Add a dependency to pom.xml and verify it downloads correctly with `mvn dependency:resolve`.

## Practice 3: Multi-Module Setup
Create a parent pom.xml with two child modules (core and api).

## Practice 4: Package Organization
Organize a project with proper package structure: model, service, repository, and controller layers.

## Practice 5: Module System
Create a module-info.java for a project that requires java.net.http and exports its API package.
