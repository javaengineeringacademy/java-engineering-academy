# Store Inventory Management Exercises

## Exercise 1: Database Integration
Replace the FileInventoryRepository with a database implementation using JDBC or JPA/Hibernate.

**Requirements:**
- Create SQLite or H2 database schema
- Implement InventoryRepository with SQL queries
- Add connection pooling
- Handle transactions properly

**Learning Goals:**
- Database connectivity
- SQL operations
- Connection management
- Transaction handling

## Exercise 2: REST API Layer
Add a REST API layer using Spring Boot or Jakarta EE.

**Requirements:**
- Create REST endpoints for all CRUD operations
- Add input validation
- Implement error handling with proper HTTP status codes
- Add API documentation with OpenAPI/Swagger

**Learning Goals:**
- RESTful API design
- HTTP methods and status codes
- API documentation
- Request/response handling

## Exercise 3: Advanced Features
Extend the system with additional functionality:

**Requirements:**
- Add barcode/QR code generation for products
- Implement search functionality with filters
- Add import/export functionality (CSV, JSON)
- Create a simple CLI interface

**Learning Goals:**
- File format handling
- Search algorithms
- Data serialization
- CLI application development
