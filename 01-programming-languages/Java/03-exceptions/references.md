## Version History

- **Java 1.0**: Exception and Error classes introduced
- **Java 1.2**: Collection framework exceptions standardized
- **Java 5**: Generics — generic exception types
- **Java 7**: try-with-resources, multi-catch, more precise rethrow
- **Java 8**: Default methods — no new exception changes
- **Java 9**: Module system — exception class migration
- **Java 14**: Helpful NullPointerExceptions (JEP 305)
- **Java 17**: Sealed classes — sealed exception hierarchies
- **Java 21**: Virtual Threads — exception propagation changes
