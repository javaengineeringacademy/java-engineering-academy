## Version History

| Version | Change |
|---------|--------|
| JDK 1.0 | Unchecked exceptions (`RuntimeException`, `Error`) introduced |
| JDK 1.2 | `ConcurrentModificationException` added for thread-safe collections |
| JDK 5 | Enhanced for-loop and autoboxing reduced common `RuntimeException` causes |
| JDK 8 | Optional reduced `NullPointerException` frequency |
| JDK 9 | Module system affected `ClassNotFoundException` behavior |
