# Multithreading Solutions

Solutions for the practice exercises in the `practices/` folder.

## Solutions Overview

| Practice | Solution File | Description |
|----------|--------------|-------------|
| Thread Creation | ThreadSolutions.java | Thread, Runnable, Callable approaches |
| Synchronization | SyncSolutions.java | synchronized, ReentrantLock counters |
| Producer-Consumer | ProducerConsumerSolutions.java | BlockingQueue implementation |
| Thread Pool | ThreadPoolSolutions.java | ExecutorService patterns |
| CompletableFuture | CompletableFutureSolutions.java | Async pipeline |
| Deadlock Detection | DeadlockSolutions.java | ThreadMXBean detection |
| Concurrent Collections | ConcurrentCollectionsSolutions.java | HashMap vs ConcurrentHashMap |
| Atomic Variables | AtomicSolutions.java | AtomicLong, LongAdder, CAS stack |

## How to Use

1. Open the corresponding practice file in `practices/`
2. Read the problem statement and attempt the exercise
3. Check the solution in `solutions/` if stuck
4. Run the solution's main method to verify correctness
