# Deque — Quiz

## Multiple Choice

1. Which class implements Deque in Java?
   - A) ArrayDeque
   - B) PriorityQueue
   - C) LinkedList
   - D) Both A and C

2. What is the time complexity of addFirst() in ArrayDeque?
   - A) O(n)
   - B) O(log n)
   - C) O(1)
   - D) O(n²)

3. Which method removes and returns the first element?
   - A) peek()
   - B) poll()
   - C) remove()
   - D) element()

4. ArrayDeque is:
   - A) Thread-safe
   - B) Not thread-safe
   - C) Synchronized
   - D) Concurrent

5. What is the initial capacity of ArrayDeque?
   - A) 8
   - B) 16
   - C) 32
   - D) 64

## True/False

6. Deque can be used as both queue and stack.
7. ArrayDeque is faster than LinkedList for queue operations.
8. Deque allows null elements.
9. ArrayDeque implements Queue interface.
10. Deque has fixed size.

## Answers

1. D, 2. C, 3. B, 4. B, 5. B
6. True, 7. True, 8. False, 9. True, 10. False
