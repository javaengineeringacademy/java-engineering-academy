- **Java 1.2**: Set interface introduced as part of Collections Framework
- **Java 5**: Generics added — type-safe Set
- **Java 8**: Default methods, stream() support, removeIf()
- **Java 9**: Set.of() factory methods — immutable sets
- **Java 10**: Set.copyOf() immutable copies
