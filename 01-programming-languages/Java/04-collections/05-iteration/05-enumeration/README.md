# Enumeration Pattern

## Overview
Legacy iteration interface for Vector and Hashtable.

## Directory Structure
- `00-examples/` - Example code demonstrating Enumeration
- `01-exercises/` - Practice exercises to complete
- `02-solutions/` - Solutions to exercises
- `03-internals/` - Internal documentation and details
- `04-memory/` - Memory behavior documentation

## Key Concepts
- Legacy Java 1.0 interface
- Synchronized access
- No removal support

## Quick Start
1. Review `00-examples/EnumerationExample.java`
2. Complete exercises in `01-exercises/`
3. Check solutions in `02-solutions/`
