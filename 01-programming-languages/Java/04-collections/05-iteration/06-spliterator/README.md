# Spliterator Pattern

## Overview
Splittable Iterator for parallel stream processing.

## Directory Structure
- `00-examples/` - Example code demonstrating Spliterator
- `01-exercises/` - Practice exercises to complete
- `02-solutions/` - Solutions to exercises
- `03-internals/` - Internal documentation and details
- `04-memory/` - Memory behavior documentation

## Key Concepts
- Parallel traversal
- trySplit() for divide-and-conquer
- Stream characteristics

## Quick Start
1. Review `00-examples/SpliteratorExample.java`
2. Complete exercises in `01-exercises/`
3. Check solutions in `02-solutions/`
