# Enhanced For Loop Iteration

## Overview
Syntactic sugar for Iterator-based iteration.

## Directory Structure
- `00-examples/` - Example code demonstrating enhanced for loop
- `01-exercises/` - Practice exercises to complete
- `02-solutions/` - Solutions to exercises
- `03-internals/` - Internal documentation and details
- `04-memory/` - Memory behavior documentation

## Key Concepts
- Implicit Iterator creation
- Read-only iteration pattern
- ConcurrentModificationException

## Quick Start
1. Review `00-examples/EnhancedForExample.java`
2. Complete exercises in `01-exercises/`
3. Check solutions in `02-solutions/`
