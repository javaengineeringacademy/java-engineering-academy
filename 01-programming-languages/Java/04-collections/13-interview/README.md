# Collections Interview Preparation

## Scope

This folder provides interview-focused questions and answers covering the Java Collections Framework.

## Contents

- **interview-questions.md**: 50+ interview questions with detailed answers covering all collection types

## Question Categories

### Fundamentals
- Collection vs Collections utility class
- Collection hierarchy and interfaces
- Time and space complexity trade-offs

### List Implementation
- ArrayList vs LinkedList selection criteria
- Vector vs ArrayList (thread-safety implications)
- CopyOnWriteArrayList use cases

### Set and Map
- HashSet vs TreeSet vs LinkedHashSet
- HashMap internals (hashing, collisions, treeification)
- ConcurrentHashMap strategies (segment locking vs CAS)
- TreeMap vs LinkedHashMap selection

### Queue and Deque
- PriorityQueue ordering guarantees
- BlockingQueue producer-consumer patterns
- ArrayDeque vs Stack for LIFO operations

### Streams and Lambda
- Stream pipeline execution model
- Parallel streams and ForkJoinPool
- Functional interface selection (Predicate, Function, Consumer, Supplier)

## How to Use

1. Review questions before interviews
2. Practice explaining answers aloud
3. Focus on understanding "why" not just "what"
4. Be prepared for follow-up questions on internals
