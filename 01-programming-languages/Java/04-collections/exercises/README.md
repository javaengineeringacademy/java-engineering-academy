# Collection Exercises

## Overview

Practice exercises for the Java Collections Framework. Complete each exercise to reinforce your understanding.

## List Exercises

1. Remove duplicates from a list while preserving order
2. Rotate a list by n positions
3. Chunk a list into sublists of size k
4. Interleave two lists alternately
5. Find the intersection of two lists

## Set Exercises

1. Find common elements between two lists using Set
2. Check if one set is a subset of another
3. Implement symmetric difference of two sets
4. Remove all elements from set1 that are in set2
5. Find all anagram groups in a word list

## Map Exercises

1. Count word frequencies in a string
2. Sort a map by values
3. Group elements by a classifier function
4. Implement a simple LRU cache using LinkedHashMap
5. Merge two maps, summing values for common keys

## Sorting Exercises

1. Sort a list of strings by length, then alphabetically
2. Sort a map by keys, then by values for ties
3. Implement a stable sort for objects with multiple fields
4. Sort employees by department, then by name
5. Sort a list using only Comparator composition

## Iterator Exercises

1. Use Iterator to safely remove elements matching a predicate
2. Implement bidirectional traversal using ListIterator
3. Create a custom iterator that filters elements
4. Demonstrate ConcurrentModificationException and fix it
5. Implement a peekable iterator wrapper
