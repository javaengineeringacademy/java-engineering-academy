# Java Topic Template

Standard template for every Java topic.

---

## Overview

Brief description of what this topic is and why it matters.

**Purpose:** Provide context and motivation for the topic. Explain where it fits in the broader Java ecosystem.

---

## How It Works

Step-by-step explanation of the mechanism.

**Purpose:** Break down the concept into clear, sequential steps. Use diagrams or pseudocode where helpful.

---

## Why It Works This Way

Design rationale. Why was this approach chosen over alternatives?

**Purpose:** Explain the historical and technical reasoning behind the design. Compare with other languages or approaches.

---

## Memory Implications

How this topic affects memory usage. Where objects live. Memory overhead.

**Purpose:** Describe memory layout, object lifecycle, heap vs stack allocation, and memory overhead costs.

---

## Performance Characteristics

Time complexity. Space complexity. When performance matters.

**Purpose:** Quantify performance impact. Provide benchmarks or complexity analysis where applicable.

---

## OpenJDK Implementation

How this is implemented in OpenJDK source code. Link to source walkthrough.

**Purpose:** Reference specific OpenJDK classes, methods, or HotSpot internals. Link to JDK source on GitHub.

---

## Code Examples

Runnable Java examples demonstrating the concept.

**Purpose:** Provide working, compilable code snippets. Include expected output.

---

## Common Pitfalls

What goes wrong. How to avoid it.

**Purpose:** Highlight frequent mistakes and misconceptions. Show before/after patterns.

---

## Best Practices

Industry-proven practices.

**Purpose:** List actionable guidelines that developers should follow in production code.

---

## When to Use / When NOT to Use

Decision guide for applying this knowledge.

**Purpose:** Help developers decide when this concept is appropriate and when alternatives are better.

---

## Interview Questions

5-8 questions with answers.

**Purpose:** Prepare developers for technical interviews. Cover foundational and advanced questions.

---

## References

Links to official documentation, books, talks.

**Purpose:** Point to authoritative sources for further reading.

---

## Template Usage Instructions

1. Copy this template into a new directory under `01-programming-languages/Java/`
2. Name the directory after the topic (e.g., `generics`, `concurrency`, `memory-model`)
3. Rename the file to `README.md`
4. Fill in each section following the guidance provided
5. Run the content checklist against your work before publishing
