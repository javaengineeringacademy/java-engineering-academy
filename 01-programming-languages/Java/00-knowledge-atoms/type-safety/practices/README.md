# Type Safety Exercises

Practice Java type safety concepts with these exercises.

## Exercises

1. **Exercise1_Casting.java** - Safe casting with instanceof
2. **Exercise2_Generics.java** - Generic type safety
3. **Exercise3_Wildcards.java** - Upper and lower bounded wildcards
4. **Exercise4_TypeErasure.java** - Workarounds for type erasure

## Instructions

1. Open each exercise file
2. Follow the instructions in the comments
3. Implement the missing code
4. Run your solution to verify it works
5. Check the solutions folder when ready

## Hints

- Use `instanceof` before casting to avoid ClassCastException
- Generics provide compile-time type safety
- Wildcards (`? extends`, `? super`) add flexibility
- Type erasure removes generic type info at runtime
