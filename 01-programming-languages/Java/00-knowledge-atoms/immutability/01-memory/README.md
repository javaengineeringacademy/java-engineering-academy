# Memory: Immutability

## Overview
This folder contains memory-related demonstrations for immutability.

## Files
- `ImmutabilityMemory.java` — Demonstrates memory implications of immutable objects and defensive copying

## What You'll Learn
- Memory overhead of defensive copying
- How immutability affects object caching and reuse
- Memory cost of String immutability vs StringBuilder
- Trade-offs between immutability and memory consumption

## Key Concepts
- Defensive copy memory overhead (doubling object count)
- String pool memory optimization
- Immutable collection memory footprint
- Cache-friendly immutable objects
