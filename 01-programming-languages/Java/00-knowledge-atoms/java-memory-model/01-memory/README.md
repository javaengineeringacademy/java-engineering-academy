# Memory: Java Memory Model

## Overview
This folder contains memory-related demonstrations for the Java Memory Model.

## Files
- `JavaMemoryModelMemory.java` — Demonstrates memory visibility, volatile behavior, and thread-local storage

## What You'll Learn
- How thread-local memory (registers, caches) interacts with main memory
- Memory barriers and their effect on CPU caches
- How volatile writes flush to main memory
- Memory overhead of synchronization mechanisms

## Key Concepts
- CPU cache coherence and memory barriers
- Store buffer and invalidate queue effects
- False sharing and cache line padding
- Memory cost of volatile vs synchronized
