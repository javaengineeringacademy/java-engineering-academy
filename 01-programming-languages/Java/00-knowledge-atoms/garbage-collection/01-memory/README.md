# Memory: Garbage Collection

## Overview
This folder contains memory-related demonstrations for garbage collection.

## Files
- `GarbageCollectionMemory.java` — Demonstrates GC behavior, memory allocation patterns, and heap analysis

## What You'll Learn
- How object allocation affects heap memory
- GC pause times and their impact on application latency
- Memory usage patterns with different reference types
- How to measure and monitor heap memory usage

## Key Concepts
- Eden allocation and Minor GC frequency
- Old generation promotion and Major GC pauses
- Soft/Weak reference memory retention
- Heap dump analysis for memory leaks
