## Key Concepts
| Concept | Description |
|---------|-------------|
| Encapsulation | Bundling data and methods; controlling access |
| Inheritance | Code reuse through "is-a" relationships |
| Polymorphism | One interface, many implementations |
| Abstraction | Hiding complexity behind contracts |
| Composition | Building complex objects from simpler ones |

## Design Principles
- **SOLID** - Single Responsibility, Open-Closed, Liskov Substitution, Interface Segregation, Dependency Inversion
- **GRASP** - General Responsibility Assignment Software Patterns
- **Composition over Inheritance** - Prefer HAS-A over IS-A
- **Program to Interface, Not Implementation** - Depend on abstractions
