# 06. GC Algorithms - Practices

## Exercise Files

| File | Difficulty | Topic |
|------|-----------|-------|
| `Exercise1.java` | Easy | Compare G1, ZGC, and Shenandoah performance |
| `Exercise2.java` | Medium | Tune G1 parameters for a specific workload |
| `Exercise3.java` | Hard | Analyze GC logs and optimize for a latency target |

## How to Complete These Exercises

1. Read the exercise description in each file
2. Implement the TODO sections
3. Compile and run to verify your solution
4. Compare with the solutions in `../solutions/`

## Prerequisites

- JDK 17+ installed (ZGC and Shenandoah available)
- Understanding of GC algorithm internals from README
- Basic knowledge of JVM flags
