# 02. ClassLoader - Practices

## Exercise Files

| File | Difficulty | Topic |
|------|-----------|-------|
| `Exercise1.java` | Easy | Map the classloader hierarchy for different classes |
| `Exercise2.java` | Medium | Implement a custom classloader that loads from a directory |
| `Exercise3.java` | Hard | Detect and prevent classloader memory leaks |

## How to Complete These Exercises

1. Read the exercise description in each file
2. Implement the TODO sections
3. Compile and run to verify your solution
4. Compare with the solutions in `../solutions/`

## Prerequisites

- JDK 17+ installed
- Understanding of parent delegation model from README
- Basic knowledge of Java I/O and reflection
