# 03. Class Loading - Practices

## Exercise Files

| File | Difficulty | Topic |
|------|-----------|-------|
| `Exercise1.java` | Easy | Observe class loading phases with verbose output |
| `Exercise2.java` | Medium | Explore static initialization order and circular dependencies |
| `Exercise3.java` | Hard | Implement lazy loading with classloader lifecycle management |

## How to Complete These Exercises

1. Read the exercise description in each file
2. Implement the TODO sections
3. Compile and run to verify your solution
4. Compare with the solutions in `../solutions/`

## Prerequisites

- JDK 17+ installed
- Understanding of class loading phases from README
- Basic knowledge of Java reflection
