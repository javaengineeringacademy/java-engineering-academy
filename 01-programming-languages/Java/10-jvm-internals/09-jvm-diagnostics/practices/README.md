# 09. JVM Diagnostics - Practices

## Exercise Files

| File | Difficulty | Topic |
|------|-----------|-------|
| `Exercise1.java` | Easy | Capture and analyze thread dumps |

## How to Complete These Exercises

1. Read the exercise description in each file
2. Implement the TODO sections
3. Compile and run to verify your solution
4. Compare with the solutions in `../solutions/`

## Prerequisites

- JDK 17+ installed
- Understanding of diagnostic tools from README
- Basic knowledge of thread dumps and heap dumps
