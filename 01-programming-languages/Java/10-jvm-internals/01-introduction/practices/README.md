# 01. JVM Introduction - Practices

## Exercise Files

| File | Difficulty | Topic |
|------|-----------|-------|
| `JvmExplorer.java` | Easy | Explore JVM runtime properties |
| `MemoryInspector.java` | Medium | Inspect heap and stack memory |
| `ClassloaderHierarchy.java` | Medium | Map the class loader delegation chain |

## How to Complete These Exercises

1. Read the exercise description in each file
2. Implement the TODO sections
3. Compile and run to verify your solution
4. Compare with the solutions in `../solutions/`

## Prerequisites

- JDK 17+ installed
- Basic Java knowledge
- Understanding of JVM architecture from the README
