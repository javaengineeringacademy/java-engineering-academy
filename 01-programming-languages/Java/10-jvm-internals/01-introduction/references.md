# 01. Introduction to JVM - References

## Official Documentation
- [JVM Specification](https://docs.oracle.com/javase/specs/jvms/se21/html/index.html) - The authoritative JVM specification
- [Oracle JVM Documentation](https://docs.oracle.com/javase/vm/) - Oracle's official JVM documentation
- [OpenJDK](https://openjdk.org/) - Open source JDK reference implementation

## Books
- *Inside the Java Virtual Machine* by Bill Venners - Classic deep dive into JVM internals
- *Java Performance* by Scott Oaks - Comprehensive guide to JVM performance tuning
- *Optimizing Java* by Benjamin J. Evans, Jason Clark, and John Oliver
- *Effective Java* by Joshua Bloch - Best practices that leverage JVM understanding
