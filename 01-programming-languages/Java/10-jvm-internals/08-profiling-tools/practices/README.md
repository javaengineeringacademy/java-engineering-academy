# 08. Profiling Tools - Practices

## Exercise Files

| File | Difficulty | Topic |
|------|-----------|-------|
| `Exercise1.java` | Easy | Profile CPU hotspots with async-profiler |
| `Exercise2.java` | Medium | Detect memory allocation hotspots |

## How to Complete These Exercises

1. Read the exercise description in each file
2. Implement the TODO sections
3. Compile and run to verify your solution
4. Compare with the solutions in `../solutions/`

## Prerequisites

- JDK 17+ installed
- async-profiler installed (https://github.com/async-profiler/async-profiler)
- Basic knowledge of profiling concepts from README
