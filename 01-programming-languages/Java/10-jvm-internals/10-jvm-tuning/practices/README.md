# 10. JVM Tuning - Practices

## Exercise Files

| File | Difficulty | Topic |
|------|-----------|-------|
| `Exercise1.java` | Easy | Measure baseline performance with different heap sizes |
| `Exercise2.java` | Medium | Tune GC for a specific latency target |
| `Exercise3.java` | Hard | Optimize container JVM configuration |

## How to Complete These Exercises

1. Read the exercise description in each file
2. Implement the TODO sections
3. Compile and run to verify your solution
4. Compare with the solutions in `../solutions/`

## Prerequisites

- JDK 17+ installed
- Understanding of JVM tuning from README
- Basic knowledge of GC algorithms
