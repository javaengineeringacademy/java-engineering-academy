# 12. Module System - Practices

## Exercise Files

| File | Difficulty | Topic |
|------|-----------|-------|
| `Exercise1.java` | Easy | Create a basic module with exports |
| `Exercise2.java` | Medium | Implement service provider interface with modules |
| `Exercise3.java` | Hard | Migrate a classpath application to module system |

## How to Complete These Exercises

1. Read the exercise description in each file
2. Implement the TODO sections
3. Compile and run to verify your solution
4. Compare with the solutions in `../solutions/`

## Prerequisites

- JDK 17+ installed
- Understanding of module system from README
- Basic knowledge of Java packages and imports
