# 11. JVM Security - Practices

## Exercise Files

| File | Difficulty | Topic |
|------|-----------|-------|
| `Exercise1.java` | Easy | Configure and test Security Manager policies |
| `Exercise2.java` | Medium | Implement deserialization filtering |
| `Exercise3.java` | Hard | Analyze bytecode verification failures |

## How to Complete These Exercises

1. Read the exercise description in each file
2. Implement the TODO sections
3. Compile and run to verify your solution
4. Compare with the solutions in `../solutions/`

## Prerequisites

- JDK 17+ installed (Security Manager deprecated but still functional)
- Understanding of JVM security from README
- Basic knowledge of Java security APIs
