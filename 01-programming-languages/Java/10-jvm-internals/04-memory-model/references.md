# 04. Memory Model - References

## Official Documentation
- [Java Memory Model (JLS Chapter 17)](https://docs.oracle.com/javase/specs/jls/se21/html/jls-17.html) — Authoritative JMM specification
- [JSR 133: Java Memory Model and Thread Specification](https://www.cs.umd.edu/~pugh/java/memoryModel/) — Original JMM specification
- [volatile Keyword](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/lang/Thread.html) — Thread documentation including memory effects

## Books
- *Java Concurrency in Practice* by Brian Goetz — The definitive guide to JMM and concurrent programming
- *Java Memory Model* by Jeremy Manson, Brian Goetz, and the JSR 133 Expert Group
- *Effective Java* by Joshua Bloch — Item 66-78 cover concurrent programming
