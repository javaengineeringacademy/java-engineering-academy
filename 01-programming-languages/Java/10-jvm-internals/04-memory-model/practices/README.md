# 04. Memory Model - Practices

## Exercise Files

| File | Difficulty | Topic |
|------|-----------|-------|
| `Exercise1.java` | Easy | Demonstrate data races and visibility issues |
| `Exercise2.java` | Medium | Implement thread-safe lazy initialization using different techniques |
| `Exercise3.java` | Hard | Build a lock-free stack using CAS operations |

## How to Complete These Exercises

1. Read the exercise description in each file
2. Implement the TODO sections
3. Compile and run to verify your solution
4. Compare with the solutions in `../solutions/`

## Prerequisites

- JDK 17+ installed
- Understanding of happens-before rules from README
- Basic knowledge of Java concurrency
