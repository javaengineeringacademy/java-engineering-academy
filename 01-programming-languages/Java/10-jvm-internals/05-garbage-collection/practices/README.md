# 05. Garbage Collection - Practices

## Exercise Files

| File | Difficulty | Topic |
|------|-----------|-------|
| `Exercise1.java` | Easy | Trigger and observe GC behavior with different collectors |
| `Exercise2.java` | Medium | Identify and fix a memory leak |
| `Exercise3.java` | Hard | Tune GC parameters for a specific workload |

## How to Complete These Exercises

1. Read the exercise description in each file
2. Implement the TODO sections
3. Compile and run to verify your solution
4. Compare with the solutions in `../solutions/`

## Prerequisites

- JDK 17+ installed
- Understanding of GC algorithms from README
- Basic knowledge of memory management
