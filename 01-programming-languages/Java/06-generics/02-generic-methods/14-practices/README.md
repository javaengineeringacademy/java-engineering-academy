# Generic Methods Exercises

Practice creating and using generic methods in Java.

## Exercises

1. **findMax** - Find the maximum element in a generic list
2. **swap** - Swap two elements in a generic array
3. **arrayToList** - Convert a generic array to a List
4. **countOccurrences** - Count occurrences of an element in an array
5. **sumOfList** - Sum numbers using different generic approaches

## Instructions

- Complete each exercise by implementing the TODO sections
- Run the main method to test your implementations
- Pay attention to type bounds and constraints

## Key Concepts

- Generic method syntax: `<T> ReturnType methodName(T param)`
- Type parameter declarations before return type
- Bounded type parameters in methods
- Wildcard vs bounded type parameters
