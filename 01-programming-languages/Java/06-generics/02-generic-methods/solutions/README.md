# Generic Methods Solutions

Complete implementations for all Generic Methods exercises.

## Solutions

1. **findMax** - Finds maximum using Comparable interface
2. **swap** - Swaps elements using temporary variable
3. **arrayToList** - Converts array to ArrayList
4. **countOccurrences** - Counts with null-safe comparison
5. **sumOfList** - Demonstrates wildcard vs bounded type approaches

## Usage

Run `GenericMethodsSolutions.java` to see all solutions in action.

## Key Takeaways

- Generic methods can exist outside generic classes
- Use `extends Comparable<T>` for methods requiring comparison
- Wildcards (`? extends Number`) provide flexibility
- Bounded types (`T extends Number`) provide type safety
