Working examples demonstrating generic methods concepts.

## Examples

- **Box.java** - Generic Box class with factory method
- **Pair.java** - Generic Pair class with utility methods

## Topics Covered

- Generic method declaration syntax
- Type inference in method calls
- Bounded type parameters
- Wildcard types in parameters
- Generic methods vs generic classes
