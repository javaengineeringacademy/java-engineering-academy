# Type Inference Exercises

Practice understanding how Java infers generic types.

## Exercises

1. **Diamond Operator** - Use `<>` to infer type arguments
2. **Method Type Inference** - Types inferred from method arguments
3. **Target Type Inference** - Target type affects inference
4. **Multiple Parameter Inference** - Inference with multiple arguments
5. **Bounded Type Inference** - Bounds affect type inference

## Instructions

- Complete each exercise by implementing the TODO sections
- Run the main method to see the output
- Observe how the compiler infers types

## Key Concepts

- Diamond operator `<>` (Java 7+)
- Type inference in method calls
- Target type inference
- Inference with bounded types
- Local variable type inference `var` (Java 10+)
