# Wildcards Solutions

Complete implementations for all Wildcards exercises.

## Solutions

1. **printList** - Iterates with Object type from unbounded wildcard
2. **sumList** - Uses `Number.doubleValue()` with upper bound
3. **addNumbers** - Adds Integer values to lower-bounded list
4. **copyList** - PECS pattern: Producer Extends, Consumer Super
5. **findMax** - Uses recursive bound for type-safe comparison

## Usage

Run `WildcardsSolutions.java` to see all solutions in action.

## Key Takeaways

- Unbounded wildcards are read-only
- Upper bounds allow reading specific types
- Lower bounds allow writing specific types
- Wildcards cannot be used in class/type declarations
