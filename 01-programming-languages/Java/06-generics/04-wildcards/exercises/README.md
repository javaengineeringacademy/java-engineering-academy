# Wildcards Exercises

Practice using different types of wildcards in Java generics.

## Exercises

1. **printList** - Print any list using unbounded wildcard
2. **sumList** - Sum numbers using upper-bounded wildcard
3. **addNumbers** - Add integers using lower-bounded wildcard
4. **copyList** - Copy between lists using both bounds
5. **findMax** - Find maximum with recursive bound wildcard

## Instructions

- Complete each exercise by implementing the TODO sections
- Run the main method to test your implementations
- Understand when to use each wildcard type

## Key Concepts

- Unbounded wildcard: `<?>`
- Upper-bounded: `<? extends Type>`
- Lower-bounded: `<? super Type>`
- PECS principle: Producer Extends, Consumer Super
