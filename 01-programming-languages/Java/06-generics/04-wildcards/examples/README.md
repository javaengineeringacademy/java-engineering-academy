# Wildcards Examples

Working examples demonstrating wildcard types.

## Examples

- **BoundedTypeDemo.java** - Demonstrates upper and lower bounded wildcards

## Topics Covered

- Unbounded wildcards `<?>`
- Upper-bounded wildcards `<? extends T>`
- Lower-bounded wildcards `<? super T>`
- PECS principle (Producer Extends, Consumer Super)
- Wildcards in method parameters
