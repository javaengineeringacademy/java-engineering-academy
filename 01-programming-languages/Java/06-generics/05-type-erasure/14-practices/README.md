# Type Erasure Exercises

Understand how Java implements generics through type erasure.

## Exercises

1. **Type Erasure at Runtime** - Show generic types are erased at runtime
2. **instanceof with Generics** - Learn why instanceof doesn't work with generics
3. **Bridge Methods** - Discover synthetic bridge methods
4. **Generic Arrays** - Understand why generic arrays are not allowed
5. **Bounded Type Erasure** - See how bounded types are erased

## Instructions

- Complete each exercise by implementing the TODO sections
- Run the main method to see the output
- Observe the actual runtime behavior

## Key Concepts

- Type parameters are erased to their bounds or Object
- Bridge methods maintain polymorphism
- Generic array creation is not allowed
- Raw types bypass type checking (unsafe)
