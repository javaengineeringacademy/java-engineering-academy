# Erasure of Generic Methods Exercises

Understand how type erasure affects generic methods.

## Exercises

1. **Method Type Parameter Erasure** - Method type parameters are erased
2. **Bounded Type Erasure** - T replaced by bound at runtime
3. **Bridge Methods** - Synthetic methods from overriding
4. **Multiple Bound Erasure** - First bound replaces type parameter
5. **Runtime Type Checking** - Type checking limitations

## Instructions

- Complete each exercise by implementing the TODO sections
- Run the main method to see the output
- Use reflection to inspect method signatures

## Key Concepts

- Method type parameters erased to Object or bound
- Bridge methods generated for overrides
- First bound used for multiple bounds
- Class<T> parameter for runtime type checking
