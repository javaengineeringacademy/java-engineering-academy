# Generic Types Exercises

Practice creating and using generic classes and interfaces in Java.

## Exercises

1. **Pair Class** - Create a generic Pair that holds two values of different types
2. **Box Class** - Create a generic Box that wraps any type with null-safety
3. **Stack Class** - Implement a generic stack with standard operations
4. **makePair Method** - Create a generic utility method
5. **Container Interface** - Define and implement a generic interface

## Instructions

- Complete each exercise by implementing the TODO sections
- Run the main method to test your implementations
- All classes are static inner classes for easy testing

## Key Concepts

- Generic class declaration with type parameters
- Type parameter naming conventions (T, E, K, V, A, B)
- Bounded type parameters (covered in later topics)
- Generic interfaces and their implementations
