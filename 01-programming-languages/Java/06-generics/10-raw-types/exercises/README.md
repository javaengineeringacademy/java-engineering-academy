# Raw Types Exercises

Understand raw types and why they should be avoided.

## Exercises

1. **Raw vs Parameterized** - Compare raw type and parameterized type usage
2. **Unsafe Operations** - Show how raw types bypass type checking
3. **Method Parameters** - Issues with raw type parameters
4. **Raw vs Wildcard** - Compare raw type and unbounded wildcard
5. **Necessary Raw Types** - When raw types are required

## Instructions

- Complete each exercise by implementing the TODO sections
- Run the main method to see the output
- Observe compilation warnings for raw types

## Key Concepts

- Raw types bypass type checking
- Use parameterized types instead of raw types
- Wildcards maintain type safety
- @SuppressWarnings("rawtypes") to acknowledge raw type usage
- Raw types are necessary for legacy code and reflection
