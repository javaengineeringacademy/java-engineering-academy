## Common Options

### java command
- `-version`: Show version
- `-verbose:class`: Show class loading
- `-Xmx`: Set maximum heap size
- `-Xms`: Set initial heap size
- `-jar`: Run jar file

### javac command
- `-version`: Show compiler version
- `-Xlint`: Enable all warnings
- `-d`: Set output directory
- `-cp`: Set classpath

### jar command
- `c`: Create jar
- `x`: Extract jar
- `t`: List contents
- `v`: Verbose output
- `f`: Specify jar file
