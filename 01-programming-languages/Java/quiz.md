## Quiz 1: Variables and Data Types

### Question 1

- A) 0
- B) null
- C) undefined
- D) 1

**Answer: A**

### Question 2
Which of the following is NOT a primitive data type in Java?
- A) int
- B) boolean
- C) String
- D) double

**Answer: C**

### Question 3
What is the range of byte data type in Java?
- A) -128 to 127
- B) -256 to 255
- C) -32768 to 32767
- D) 0 to 255

**Answer: A**

### Question 4
Which keyword is used to declare a constant in Java?
- A) final
- B) const
- C) static
- D) volatile

**Answer: A**

### Question 5
What is the size of a double in Java?
- A) 32 bits
- B) 64 bits
- C) 128 bits
- D) 16 bits

## Quiz 3: Control Flow

### Question 1
Which statement is used to exit a loop prematurely?
- A) break
- B) continue
- C) return
- D) exit

**Answer: A**

### Question 2
What is the output of the following code?
```java
for (int i = 0; i < 5; i++) {
    if (i == 3) continue;
    System.out.print(i + " ");
}
```
- A) 0 1 2 3 4
- B) 0 1 2 4
- C) 0 1 2
- D) 3

**Answer: B**

### Question 3
Which loop is guaranteed to execute at least once?
- A) for loop
- B) while loop
- C) do-while loop
- D) enhanced for loop

**Answer: C**

### Question 4
What is a switch statement used for?
- A) Looping
- B) Conditional branching
- C) Exception handling
- D) Method calling

**Answer: B**

### Question 5
What happens if you don't break in a switch case?
- A) Compilation error
- B) Runtime error
- C) Fall-through to next case
- D) Nothing

**Answer: C**

## Quiz 4: Methods

### Question 1
What is method overloading?
- A) Same method name, different parameters
- B) Same method name, same parameters
- C) Different method name, same parameters
- D) Different method name, different parameters

**Answer: A**

### Question 2
What is the return type of a method that doesn't return anything?
- A) void
- B) null
- C) empty
- D) none

**Answer: A**

### Question 3
Can a method have multiple return statements?
- A) Yes, always
- B) Yes, but only in different branches
- C) No, never
- D) Only in static methods

**Answer: B**

### Question 4
What is a static method?
- A) A method that belongs to the class
- B) A method that belongs to an instance
- C) A method that can't be overridden
- D) A method that can't be overloaded

**Answer: A**

### Question 5
What is the difference between final, finally, and finalize?
- A) final is keyword, finally is block, finalize is method
- B) All are keywords
- C) All are blocks
- D) All are methods
