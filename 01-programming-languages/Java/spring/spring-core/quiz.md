# Spring Core Quiz

## Quiz 1: IoC and DI

### Question 1
What is IoC (Inversion of Control)?
- A) Framework manages object lifecycle
- B) Developer manages object lifecycle
- C) No one manages object lifecycle
- D) Runtime manages object lifecycle

**Answer: A**

### Question 2
What is Dependency Injection?
- A) Providing dependencies from outside
- B) Creating dependencies inside
- C) No dependencies
- D) Static dependencies

**Answer: A**

### Question 3
What are the types of DI?
- A) Constructor, Setter, Interface
- B) Constructor, Method, Field
- C) Setter, Getter, Field
- D) Constructor, Setter, Method

**Answer: A**

### Question 4
What is the benefit of DI?
- A) Loose coupling
- B) Testability
- C) Both A and B
- D) Neither

**Answer: C**

### Question 5
What is the difference between IoC and DI?
- A) IoC is concept, DI is implementation
- B) IoC is implementation, DI is concept
- C) Both are concepts
- D) Both are implementations

**Answer: A**

## Quiz 2: Spring Beans

### Question 1
What is a Spring Bean?
- A) Object managed by Spring container
- B) Object managed by developer
- C) Object managed by JVM
- D) Object managed by garbage collector

**Answer: A**

### Question 2
What is @Component annotation?
- A) Marks class as Spring bean
- B) Marks method as Spring bean
- C) Marks variable as Spring bean
- D) Marks package as Spring bean

**Answer: A**

### Question 3
What is the difference between @Component, @Service, @Repository?
- A) All are stereotypes, different semantics
- B) Different functionality
- C) Different scopes
- D) Different lifecycles

**Answer: A**

### Question 4
What is bean scope?
- A) Lifecycle of bean
- B) Location of bean
- C) Name of bean
- D) Type of bean

**Answer: A**

### Question 5
What are the bean scopes?
- A) Singleton, Prototype, Request, Session
- B) Singleton, Prototype, Global, Local
- C) Singleton, Multiple, Request, Session
- D) Singleton, Prototype, Static, Dynamic

**Answer: A**

- B) Way to destroy beans
- C) Way to create beans

### Question 2

- B) Marks class as event listener
- C) Marks variable as event listener
- D) Marks package as event listener

- C) Abstract class for events
