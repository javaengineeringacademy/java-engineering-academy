# JavaScript Design Patterns

## Overview

Design patterns provide reusable solutions to common software design problems. JavaScript's
dynamic nature, first-class functions, and prototypal inheritance enable unique
implementations of classic GoF patterns. This module covers all 23 GoF patterns plus
JavaScript-specific patterns.

## Pattern Categories

### Creational Patterns
- **Singleton** - Module pattern implementation
- **Factory** - Factory functions and constructors
- **Abstract Factory** - Factory of factories
- **Builder** - Fluent builder pattern
- **Prototype** - Prototype chain and prototypal inheritance

### Structural Patterns
- **Adapter** - Interface conversion
- **Decorator** - Higher-order functions
- **Facade** - Simplified interface
- **Proxy** - ES6 Proxy对象
- **Composite** - Tree structure handling
- **Bridge** - Abstraction decoupling
- **Flyweight** - Memory optimization

### Behavioral Patterns
- **Observer** - PubSub, EventEmitter
- **Strategy** - Algorithm encapsulation
- **Command** - Request encapsulation
- **Iterator** - Generator functions
- **State** - State machine
- **Template Method** - Algorithm skeleton
- **Chain of Responsibility** - Middleware pattern
- **Mediator** - Communication hub
- **Memento** - State capture
- **Visitor** - Operation separation
- **Interpreter** - Language grammar

## When to Use

- Building scalable web applications
- Creating reusable code libraries
- Improving code maintainability
- Team communication about architecture
- Learning functional programming patterns
