# JavaScript

A comprehensive guide to JavaScript fundamentals, asynchronous programming, DOM manipulation, modules, and testing.

## Modules

| Module | Description |
|--------|-------------|
| 01-fundamentals | Variables, operators, control flow, functions, arrays, objects, strings |
| 02-asynchronous | Callbacks, Promises, async/await |
| 03-dom | Selection, events, manipulation |
| 04-modules | ES modules, CommonJS |
| 05-testing | Jest testing framework |
| reference | Anti-patterns, best practices, comparisons, patterns |

## Quick Start

```bash
# Run any JavaScript file
node 01-fundamentals/01-variables/variables.js

# Run tests
npx jest 05-testing/01-jest/test-example.js
```

## Prerequisites

- Node.js 18+
- A code editor (VS Code recommended)

## Learning Path

1. **Fundamentals** - Variables, operators, control flow, functions, data structures
2. **Asynchronous** - Callbacks, Promises, async/await
3. **DOM** - Selection, events, manipulation
4. **Modules** - ES modules, CommonJS
5. **Testing** - Jest framework

## Running Examples

Each `.js` file is self-contained and can be executed independently:

```bash
# Variables
node 01-fundamentals/01-variables/variables.js

# Functions
node 01-fundamentals/04-functions/functions.js

# Async
node 02-asynchronous/02-promises/promises.js
```
