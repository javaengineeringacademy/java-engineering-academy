# JavaScript Hands-on Labs

## Lab 1: Task Manager

Build a command-line task manager with Node.js.

- Implement add, list, complete, delete commands
- Store tasks in JSON file
- Add due dates and priorities
- Implement search and filter
- Add color-coded output

## Lab 2: REST API

Build a RESTful API with Express.js.

- Implement CRUD operations for users
- Add input validation
- Implement pagination
- Add authentication middleware
- Handle errors consistently

## Lab 3: Real-time Chat

Build a WebSocket chat application.

- Implement WebSocket server
- Add user nicknames
- Create chat rooms
- Store message history
- Add typing indicators

## Lab 4: Weather Dashboard

Build a weather dashboard with API integration.

- Fetch weather data from API
- Display current conditions
- Show 5-day forecast
- Add location search
- Implement caching

## Lab 5: File Processor

Build a file processing utility.

- Read CSV files
- Parse and validate data
- Export to JSON format
- Implement streaming for large files
- Add progress reporting

## Lab 6: Authentication System

Build a JWT authentication system.

- Implement registration and login
- Hash passwords with bcrypt
- Generate and verify JWT tokens
- Add refresh token support
- Implement role-based access

## Lab 7: Image Gallery

Build an image gallery with upload.

- Implement file upload
- Generate thumbnails
- Add image metadata
- Implement pagination
- Add search functionality

## Lab 8: Task Scheduler

Build a task scheduler with cron-like functionality.

- Parse cron expressions
- Schedule recurring tasks
- Implement task persistence
- Add task history
- Implement graceful shutdown

## Lab 9: API Rate Limiter

Build a rate limiting middleware.

- Implement token bucket algorithm
- Add sliding window support
- Store rate limit data
- Implement different limits per user
- Add rate limit headers

## Lab 10: CLI Tool

Build a command-line interface tool.

- Implement argument parsing
- Add interactive prompts
- Support configuration files
- Implement plugins
- Add help documentation
