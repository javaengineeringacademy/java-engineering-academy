# Vue.js Fundamentals

## Overview
Vue.js is a progressive JavaScript framework for building user interfaces. Simple, flexible, and performant.

## Topics
- Template Syntax
- Components
- Props
- Events
- Computed Properties
- Watchers
- Lifecycle Hooks
- Directives
- Vue Router
- Pinia (State Management)

## Learning Objectives
- Build Vue applications
- Use composition API
- Manage state effectively

## Prerequisites
- JavaScript basics
