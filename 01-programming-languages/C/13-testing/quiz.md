# Testing Quiz

## Questions

1. What is unit testing?
2. What is the difference between unit and integration testing?
3. What is test-driven development?
4. What is code coverage?
5. What is boundary testing?
6. What is a test framework?
7. What is regression testing?
8. What is mock testing?
9. What is valgrind used for?
10. Why is testing important?
11. What is the difference between white-box and black-box testing?
12. What is a test harness?
13. What is fuzz testing and when is it useful?
14. What is the difference between assertion and verification in tests?
15. What is continuous integration and how does it relate to testing?

## Answers

1. Testing individual functions/modules
2. Unit: individual components; Integration: component interaction
3. Writing tests before writing code
4. Percentage of code executed by tests
5. Testing at boundaries of input ranges
6. Library providing test utilities and assertions
7. Re-testing after changes to ensure no regressions
8. Replacing dependencies with controlled substitutes
9. Detecting memory leaks and errors
10. Ensures reliability and catches bugs early
11. White-box: tester knows internal code structure; black-box: tester only knows inputs/outputs
12. A framework that sets up test environment, runs tests, and reports results; includes test runners, reporters, and assertion libraries
13. Automated testing with random/malformed inputs to find crashes and security bugs; useful for parsers, network services, and file format handlers
14. Assertion: programatically checks a condition in code; Verification: manual or automated review that expected behavior occurred
15. CI automatically builds and runs tests on every code commit; catches regressions early and ensures code quality throughout development
