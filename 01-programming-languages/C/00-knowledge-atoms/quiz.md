# Knowledge Atoms Quiz

## Questions

1. What are the four stages of C compilation?
2. Is C a statically or dynamically typed language?
3. What tool combines object files into executables?
4. What runs before compilation to process directives?
5. What is the memory management model in C?
6. What is the difference between a compiler and an interpreter?
7. What does the linker resolve when combining object files?
8. What is the role of the assembler in the compilation pipeline?
9. What header provides the `printf` function declaration?
10. What extension do C source files typically use?

## Answers

1. Preprocessing, Compilation, Assembly, Linking
2. Statically typed
3. The linker
4. The preprocessor
5. Manual memory management (malloc/free)
6. Compiler translates entire source to machine code at once; interpreter executes line by line
7. External symbols and function references across object files
8. Converts assembly language to machine code (object files)
9. `stdio.h`
10. `.c`
