# Knowledge Atoms — C Language

## What are Knowledge Atoms?
The fundamental concepts shared across all C programs.

## Core Concepts

### 1. Compilation Model
C is compiled — source code → object code → executable.

### 2. Type System
Static, weakly typed. Types are checked at compile time.

### 3. Memory Model
Flat memory model with manual management.

### 4. Preprocessor
Text substitution before compilation.

### 5. Linker
Combines object files into executables.
