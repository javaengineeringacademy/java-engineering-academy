# TypeScript Learning Module

## Overview
This module covers TypeScript fundamentals and advanced concepts.

## Topics Covered

### Fundamentals
- Types and type annotations
- Interfaces and extending types
- Functions with type safety
- Classes and access modifiers
- Generics and type constraints

### Advanced
- Utility types (Partial, Required, Pick, Omit, Record)
- Type guards and narrowing
- Mapped types and keyof operator

## Getting Started
```bash
# Install TypeScript
npm install -g typescript

# Compile a file
tsc filename.ts

# Watch mode
tsc --watch
```

## Directory Structure
```
typescript/
├── 01-fundamentals/     # Core TypeScript concepts
├── 02-advanced/         # Advanced type system features
└── reference/           # Best practices and patterns
```

## Prerequisites
- Node.js installed
- Basic JavaScript knowledge
- Understanding of ES6+ features
