# Kotlin Fundamentals

## Overview
Kotlin is a modern statically-typed language running on JVM. Concise, safe, and fully interoperable with Java.

## Topics
- Variables (val/var)
- Null Safety
- Functions
- Classes
- Data Classes
- Sealed Classes
- Coroutines
- Extension Functions
- Lambdas
- Collections

## Learning Objectives
- Write Kotlin code
- Use null safety features
- Leverage coroutines

## Prerequisites
- Basic programming knowledge
