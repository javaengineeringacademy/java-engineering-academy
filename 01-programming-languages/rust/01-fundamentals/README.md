# Rust Fundamentals

## Overview
Rust is a systems programming language focused on safety, speed, and concurrency. No garbage collector, no null.

## Topics
- Variables and Mutability
- Data Types
- Functions
- Control Flow
- Ownership
- References and Borrowing
- Slices
- Structs
- Enums
- Pattern Matching

## Learning Objectives
- Understand ownership system
- Write safe, fast code
- Handle memory without GC

## Prerequisites
- Basic programming knowledge
