## 🏁 Sprint 1: Java Fundamentals (COMPLETE)

### Prerequisites
- Basic programming concepts (variables, loops, functions)
- Java 21 installed
- Maven 3.9+ installed
- IDE (IntelliJ IDEA recommended)

### Learning Objectives
By the end of Sprint 1, you can:
- [x] Write, compile, and run Java programs
- [x] Use all 8 primitive types correctly
- [x] Apply operators with proper precedence
- [x] Control program flow with conditionals and loops
- [x] Work with arrays and multi-dimensional arrays
- [x] Manipulate strings efficiently (StringBuilder, formatting)
- [x] Design methods with overloading, varargs, recursion
- [x] Write clean, documented, tested code

### Study Order (Recommended)
1. **Read** `docs/theory.md` - Understand concepts
2. **Run** examples in `src/main/java/...` - See code execute
3. **Do** exercises in `exercises/exercises.md` - Practice
4. **Check** solutions in `solutions/solutions.md` - Learn patterns
5. **Test** yourself with `quiz/quiz.md` - Validate knowledge
6. **Prepare** with `interview/interview.md` - Interview ready
7. **Complete** `assignment/assignment.md` - Graded work
8. **Build** `project/` - Mini project

## 🎓 Sprint 2 Preview: OOP

### Topics
1. Classes & Objects
2. Constructors (default, parameterized, copy)
3. Methods (instance, static, final)
4. Encapsulation (private fields, getters/setters)
5. Inheritance (extends, super, method overriding)
6. Polymorphism (compile-time & runtime)
7. Abstraction (abstract classes, interfaces)
8. Object class methods (equals, hashCode, toString, clone)
9. Composition vs Aggregation vs Association
10. SOLID Principles Introduction
11. Dependency Injection Concepts

### Final Project: Bank Management System
- Account hierarchy (Savings, Checking, Credit)
- Transaction processing
- Interest calculation
- Statement generation
- Unit tests with 85%+ coverage

## 📚 Study Tips

### For Each Topic
1. **Why before How** - Read theory first, understand the problem being solved
2. **Type the Code** - Don't copy-paste; build muscle memory
3. **Break It** - Modify examples, cause errors, fix them
4. **Explain It** - Teach concept to someone (or rubber duck)
5. **Test It** - Write tests for your exercises
