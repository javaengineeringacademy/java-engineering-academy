# Learning Path

The Java Engineering Academy learning path is designed to move learners from first principles to production-grade
engineering judgment.

## 1. Java Fundamentals

Learners start with the core language model:

- Source files, packages, and compilation.
- Primitive and reference types.
- Control flow and methods.
- Records and classes.
- Exceptions and error handling.
- Basic standard library usage.

Expected outcome: learners can read, write, test, and explain small Java programs confidently.

## 2. Object-Oriented Programming

Learners build a stronger model of software design:

- Encapsulation and invariants.
- Interfaces and implementation boundaries.
- Inheritance and polymorphism.
- Composition over inheritance.
- Cohesion, coupling, and refactoring.

Expected outcome: learners can design small object models and explain trade-offs.

## 3. Collections and Generics

Learners work with the data structures used in everyday Java:

- Lists, sets, maps, queues, and iteration.
- Equality, hashing, ordering, and immutability.
- Generic classes, methods, bounds, and wildcards.
- Stream basics where they improve clarity.

Expected outcome: learners can select and use collection types correctly.

## 4. Testing and Tooling

Learners adopt professional feedback loops:

- JUnit 5 tests.
- Maven builds.
- Code coverage.
- Static analysis.
- CI workflows.
- Debugging and failure analysis.

Expected outcome: learners can verify code behavior and maintain quality gates.

## 5. Concurrency

Learners study safe concurrent programming:

- Threads and executors.
- Virtual threads.
- Shared state and synchronization.
- Race conditions and deadlocks.
- Cancellation and timeouts.

Expected outcome: learners can identify concurrency risks and use high-level concurrency tools.

## 6. Persistence and APIs

Learners connect Java programs to real systems:

- JDBC and transactions.
- Repository and service boundaries.
- HTTP APIs.
- Validation and error contracts.
- Integration testing.

Expected outcome: learners can build small services with clear boundaries and reliable tests.

## 7. Architecture and System Design

Learners move from code to systems:

- Modularity and dependency direction.
- Scalability and reliability.
- Observability.
- Data consistency.
- Trade-off communication.

Expected outcome: learners can reason about system behavior and explain architecture decisions.

## 8. Interview Readiness

Learners prepare for technical interviews:

- Java language depth.
- Data structures and algorithms.
- Object-oriented design prompts.
- System design discussions.
- Code review communication.

Expected outcome: learners can solve problems clearly and communicate engineering reasoning under time pressure.
