# Clean Code

## Principles

### Meaningful Names
Use intention-revealing names

### Functions
Small, single purpose

### Comments
Explain why, not what

### Formatting
Consistent, readable

### Error Handling
Don't return null

### Unit Tests
Test-driven development

## Rules

1. Functions should do one thing
2. Functions should be small
3. Same level of abstraction
4. Don't repeat yourself
5. Applyboy Scout Rule
