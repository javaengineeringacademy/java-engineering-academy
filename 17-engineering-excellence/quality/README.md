# Quality

## DORA Metrics

- **Deployment Frequency**: How often you deploy
- **Lead Time for Changes**: Time from commit to deploy
- **Change Failure Rate**: % of deployments causing failure
- **Mean Time to Recovery**: Time to recover from failure

## Code Quality

- Code coverage
- Cyclomatic complexity
- Technical debt
- Code duplication

## Process Quality

- Code review rate
- Defect escape rate
- Test automation rate
- Build success rate
