# Code Quality Metrics

## Metrics

### Code Coverage
Percentage of code covered by tests

### Cyclomatic Complexity
Number of independent paths through code

### Technical Debt
Cost to fix code issues

### Code Duplication
Percentage of duplicated code

### Maintainability Index
Overall code maintainability

## Tools

- SonarQube
- CodeClimate
- ESLint/Prettier
- Pylint/Black

## Thresholds

- Code coverage: > 80%
- Cyclomatic complexity: < 10
- Technical debt: Decreasing trend
- Duplication: < 3%
