# Lean Principles

## Core Principles

1. **Value**: Define value from customer perspective
2. **Value Stream**: Map the value stream
3. **Flow**: Make value flow
4. **Pull**: Let customers pull value
5. **Perfection**: Pursue perfection

## Waste Types (Muda)

1. Defects
2. Overproduction
3. Waiting
4. Non-utilized talent
5. Transportation
6. Inventory
7. Motion
8. Extra-processing
