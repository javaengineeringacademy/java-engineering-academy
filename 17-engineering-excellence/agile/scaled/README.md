# Scaled Agile Frameworks

## SAFe (Scaled Agile Framework)

- Team level
- Program level
- Portfolio level

## LeSS (Large-Scale Scrum)

- One product backlog
- One definition of done
- Feature teams

## Nexus

- 3-9 Scrum teams
- Integration team
- Common artifacts

## Choosing

- SAFe: Large enterprise
- LeSS: Medium-large teams
- Nexus: 3-9 teams
