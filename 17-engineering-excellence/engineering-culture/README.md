# Engineering Culture

## Pillars

### Blameless Postmortems
Learn from failures without blame

### Continuous Learning
Grow skills through various means

### Innovation
Experiment and try new approaches

### Collaboration
Work together effectively

### Quality Focus
Maintain high standards

## Values

1. **Transparency**: Open communication
2. **Psychological Safety**: Safe to take risks
3. **Continuous Improvement**: Always getting better
4. **Ownership**: Take responsibility
5. **Respect**: Value all perspectives
