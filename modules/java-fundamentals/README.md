# Java Fundamentals

The Java Fundamentals module introduces the language features and engineering habits that every Java developer
needs before moving into larger systems.

## Scope

- Source files, packages, and build basics.
- Values, types, control flow, and methods.
- Classes, records, encapsulation, and validation.
- Exceptions and defensive programming.
- Unit testing with JUnit 5.
- Static analysis and code coverage as daily feedback loops.

## Module Outcomes

By the end of this module, learners should be able to:

- Explain how Java source code becomes executable bytecode.
- Build small Java programs with clear package structure.
- Write tests that document expected behavior.
- Read compiler and test failures without guessing.
- Apply simple design rules that keep code understandable.
