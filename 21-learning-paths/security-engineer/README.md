# Security Engineer Learning Path

## Overview
Roadmap for application and infrastructure security.

## Stage 1: Security Fundamentals
- CIA triad
- OWASP Top 10
- Cryptography basics
- Network security

## Stage 2: Application Security
- Secure coding practices
- Code review
- SAST/DAST tools
- Penetration testing

## Stage 3: Infrastructure Security
- Cloud security
- Container security
- Network segmentation

## Stage 4: DevSecOps
- Security in CI/CD
- Infrastructure scanning
- Secret management

## Stage 5: Incident Response
- Detection and monitoring
- Forensics
- Incident handling

## Certifications
- CISSP
- CEH
- OSCP
- AWS Security Specialty
