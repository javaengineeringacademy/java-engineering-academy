## Azure Migration

Moving on-premises .NET applications to Microsoft Azure cloud infrastructure.

## Overview

Azure migration involves moving applications, data, and infrastructure to Azure services. The Cloud Adoption Framework provides structured guidance for the migration process.

## Why It Matters

- Scalability on demand
- Reduced infrastructure management
- Global availability
- Cost optimization
- Access to cloud-native services

## Key Concepts

- **Lift and Shift**: Moving without code changes
- **App Modernization**: Refactoring for cloud-native
- **Cloud Adoption Framework**: Structured migration approach
- **Azure Migrate**: Assessment and migration tool
- **Azure Arc**: Hybrid cloud management

## Core Topics

- Assessing workloads for migration
- Azure Migrate assessment
- VM migration to Azure
- Database migration to Azure SQL
- Application modernization options
- Container migration to AKS
- Cost optimization strategies

## Best Practices

- Assess before migrating
- Start with non-critical workloads
- Use Azure Migrate for discovery
- Implement monitoring post-migration
- Optimize costs with Reserved Instances

## Hands-on Labs

- Assess an application with Azure Migrate
- Migrate a web app to Azure App Service
- Migrate a database to Azure SQL
- Set up monitoring with Application Insights
