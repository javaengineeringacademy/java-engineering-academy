## Reference Implementations

Curated list of reference projects, samples, and templates for .NET engineering patterns and architectures.

## Overview

Reference implementations provide working examples of .NET patterns and architectures. They serve as starting points for new projects and learning resources.

## Why It Matters

- Learn by examining working code
- Proven patterns from Microsoft and community
- Starting points for new projects
- Best practices demonstrated in practice
- Architecture decision validation

## Key Projects

- **eShop**: Microservices reference (Blazor + .NET Aspire)
- **Clean Architecture Template**: Jason Taylor's template
- **ASP.NET Core Samples**: Official Microsoft samples
- **Orleans**: Virtual actor framework
- **MAUI**: Cross-platform desktop/mobile
- **ABP Framework**: Application framework
