## 📖 Books

### Essential Reading
1. **Effective Java (3rd Ed.)** - Joshua Bloch
   - Items 1-10: Creating and Destroying Objects
   - Items 10-14: Methods Common to All Objects
   - Items 15-19: Classes and Interfaces
   - Items 20-23: Generics
   - Items 24-26: Enums and Annotations

2. **Java: The Complete Reference** - Herbert Schildt
   - Ch. 6-12: OOP Fundamentals

3. **Head First Java** - Sierra & Bates
   - Ch. 1-9: OOP Core Concepts

4. **Design Patterns** - Gang of Four
   - Ch. 1: Introduction
   - Ch. 3-5: Creational, Structural, Behavioral Patterns

4. **Clean Code** - Robert Martin
   - Ch. 6: Objects and Data Structures
   - Ch. 11: Systems

5. **Clean Architecture** - Robert Martin
   - Ch. 2: Paradigm Overview
   - Ch. 8-12: SOLID Principles
