# Hackathon Format

## Planning

### Duration
24-48 hours typical

### Teams
3-5 people, cross-functional

### Theme
Focused problem domain

### Prizes
Innovation, impact, technical excellence

## Structure

1. Kickoff (30 min)
2. Ideation (1 hour)
3. Building (bulk of time)
4. Demos (1-2 hours)
5. Judging and prizes

## Tips

1. Ship something working
2. Focus on impact
3. Have fun
4. Learn new technologies
