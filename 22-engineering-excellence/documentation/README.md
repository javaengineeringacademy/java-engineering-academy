# Documentation

## Docs-as-Code

Write documentation like code: version controlled, reviewed, automated.

## Types

- **README**: Project overview
- **API Docs**: Interface specifications
- **Architecture Decision Records**: Design decisions
- **Runbooks**: Operational procedures
- **Onboarding Guides**: New team member docs

## Tools

- Markdown
- Static site generators
- API documentation (OpenAPI)
- Diagram tools (Mermaid, PlantUML)

## Best Practices

1. Keep documentation close to code
2. Automate documentation generation
3. Review documentation with code
4. Make documentation searchable
