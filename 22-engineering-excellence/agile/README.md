# Agile Principles

## Manifesto Values

1. Individuals and interactions over processes and tools
2. Working software over comprehensive documentation
3. Customer collaboration over contract negotiation
4. Responding to change over following a plan

## Principles

1. Welcome changing requirements
2. Deliver working software frequently
3. Business people and developers work together
4. Build around motivated individuals
5. Face-to-face conversation
6. Working software is progress
7. Sustainable pace
8. Technical excellence
9. Simplicity
10. Self-organizing teams
11. Regular reflection
