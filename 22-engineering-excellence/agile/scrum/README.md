# Scrum Framework

## Roles

- **Product Owner**: Backlog management
- **Scrum Master**: Process facilitation
- **Development Team**: Cross-functional team

## Events

- **Sprint Planning**: Plan work
- **Daily Standup**: Daily sync
- **Sprint Review**: Demo work
- **Sprint Retrospective**: Improve process

## Artifacts

- **Product Backlog**: Prioritized work
- **Sprint Backlog**: Current sprint work
- **Increment**: Working software

## Values

- Commitment
- Focus
- Openness
- Respect
- Courage
