# Node.js Fundamentals

## Overview
Node.js is a JavaScript runtime for server-side development. Non-blocking I/O, event-driven architecture.

## Topics
- Event Loop
- Modules (CommonJS/ESM)
- File System
- Streams
- HTTP Server
- Express.js Basics
- Middleware
- Database Connectivity
- Authentication
- Error Handling

## Learning Objectives
- Build Node.js applications
- Create REST APIs
- Handle asynchronous operations

## Prerequisites
- JavaScript basics
