# JavaScript Fundamentals

## Overview
JavaScript is the language of the web. Dynamic, event-driven, and ubiquitous in modern development.

## Topics
- Variables (var, let, const)
- Data Types
- Functions
- Arrays
- Objects
- DOM Manipulation
- Events
- Async/Await
- Promises
- ES6+ Features

## Learning Objectives
- Write modern JavaScript
- Understand async programming
- Manipulate the DOM

## Prerequisites
- Basic programming knowledge
