# Spring WebFlux

## Overview
Spring WebFlux is the reactive web framework for building non-blocking applications.

## Topics
- Reactive Types (Mono, Flux)
- Functional Endpoints
- Netty Server
- WebClient
- Reactive Streams
- Backpressure
- Error Handling
- Testing
- WebSocket
- RSocket

## Learning Objectives
- Build reactive applications
- Use Mono and Flux
- Implement non-blocking APIs

## Prerequisites
- Spring Boot basics
- Reactive programming concepts
