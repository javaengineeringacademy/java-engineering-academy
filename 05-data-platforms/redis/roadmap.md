# Redis Learning Roadmap

## Phase 1: Fundamentals

### Core Concepts
- [ ] Learn Redis data types (Strings, Lists, Sets, Hashes)
- [ ] Understand key operations (GET, SET, DEL, EXISTS)
- [ ] Master TTL and expiration
- [ ] Practice with redis-cli

### Basic Operations
- [ ] String manipulation and counters
- [ ] List operations and queues
- [ ] Set operations and intersections
- [ ] Hash operations for objects

### Tools
- [ ] Install Redis locally
- [ ] Use Docker for Redis
- [ ] Basic redis-cli commands

### Data Structures
