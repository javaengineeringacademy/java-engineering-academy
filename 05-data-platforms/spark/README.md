# Apache Spark Fundamentals

## Overview
Apache Spark is a unified analytics engine for large-scale data processing. Fast, general-purpose, and supports multiple languages.

## Topics
- RDDs
- DataFrames
- Datasets
- Spark SQL
- Spark Streaming
- MLlib
- GraphX
- Transformations and Actions
- Partitioning
- Caching and Persistence

## Learning Objectives
- Process large datasets
- Write Spark applications
- Optimize Spark jobs

## Prerequisites
- Scala or Python basics
- Big data concepts
