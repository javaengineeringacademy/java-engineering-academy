# Cassandra Fundamentals

## Overview
Apache Cassandra is a distributed NoSQL database designed for high availability and linear scalability.

## Topics
- Data Model (Keyspaces, Tables)
- CQL (Cassandra Query Language)
- Partitioning
- Replication
- Consistency Levels
- Data Types
- Collections
- User Defined Types
- Secondary Indexes
- Materialized Views

## Learning Objectives
- Design Cassandra data models
- Write efficient CQL queries
- Ensure high availability

## Prerequisites
- Database concepts
- Distributed systems basics
