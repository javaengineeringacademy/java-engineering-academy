# PostgreSQL Fundamentals

## Overview
PostgreSQL is a powerful, open-source relational database with advanced features and SQL compliance.

## Topics
- Data Types
- Tables and Constraints
- Joins
- Subqueries
- Window Functions
- CTEs (Common Table Expressions)
- Indexes
- Views
- Stored Procedures
- Triggers

## Learning Objectives
- Write complex SQL queries
- Optimize database performance
- Implement business logic in DB

## Prerequisites
- Basic SQL knowledge
