# Elasticsearch Fundamentals

## Overview
Elasticsearch is a distributed, RESTful search and analytics engine. Fast, scalable, and flexible.

## Topics
- Documents and Indices
- Mapping
- Query DSL
- Full Text Search
- Aggregations
- Cluster Management
- Shards and Replicas
- Index Templates
- Ingest Pipelines
- Kibana Integration

## Learning Objectives
- Index documents
- Write complex queries
- Optimize search performance

## Prerequisites
- REST concepts
- JSON basics
