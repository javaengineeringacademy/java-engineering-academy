# JBoss Enterprise Application Platform (EAP)

## Overview

JBoss EAP is Red Hat's commercially supported Java EE application server based on WildFly. It provides enterprise-grade support, certification, and stability for mission-critical applications.

## Relationship to WildFly

JBoss EAP is derived from WildFly with additional stabilization, backporting of fixes, and commercial support. Features are first developed in WildFly and later stabilized for EAP releases.

## Subscription Benefits

Red Hat subscription includes 24/7 support, security patches, certified configurations, and access to the Red Hat Customer Portal. LTS releases provide extended support timelines.

## Management

JBoss EAP provides CLI, Management Console, and Management API similar to WildFly. Domain mode enables centralized management of multiple server instances across environments.

## OpenShift Integration

JBoss EAP integrates with Red Hat OpenShift for container-based deployments. The EAP operator automates deployment, scaling, and management on Kubernetes infrastructure.

## Migration

Red Hat provides migration tools and guidance for moving from older JBoss versions or other application servers. The migration toolkit assesses applications for compatibility and required changes.

## Certification

JBoss EAP is certified for Java EE Full Platform compliance. It is certified for use with Red Hat Enterprise Linux, OpenShift, and various databases and middleware products.

## Cost Considerations

JBoss EAP requires paid subscriptions per core. Organizations should evaluate support requirements, certification needs, and total cost of ownership compared to community WildFly or alternatives.
