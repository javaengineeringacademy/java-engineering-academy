# Payara Server

## Overview

Payara Server is a fork of GlassFish Server maintained by Payara Services Ltd. It provides commercially supported Java EE application server with regular releases, bug fixes, and production support.

## Relationship to GlassFish

Payara originated from Oracle GlassFish after Oracle reduced commercial support. Payara enhances GlassFish with additional fixes, security patches, and features for production deployment.

## Payara Server vs Payara Micro

Payara Server provides full Java EE support for traditional deployments. Payara Micro is a lightweight, embeddable server for microservices and cloud-native applications with fast startup.

## Administration

Payara provides asadmin CLI, web-based Administration Console, and REST API for management. Payara Cloud offers fully managed deployment without infrastructure management.

## Release Cycle

Payara follows a predictable release cycle with quarterly releases. Each release includes security fixes, bug fixes, and selected feature backports from community GlassFish development.

## Cloud Support

Payara Micro deploys to Docker containers, Kubernetes, and cloud platforms. Payara Server supports deployment to traditional infrastructure with clustering and high availability.

## Migration

Migrating from GlassFish or other application servers to Payara is generally straightforward due to shared GlassFish heritage. Configuration files and deployment procedures are compatible.

## Commercial Support

Payara provides subscription-based support with SLA guarantees, patch releases, and technical support. Community editions are available for development and evaluation without support.
