# Oracle Application Server

## Overview

Oracle Application Server (OracleAS) was Oracle's middleware platform for hosting Java EE applications. Released in the early 2000s, it was eventually superseded by Oracle WebLogic Server after the BEA Systems acquisition.

## Historical Context

Oracle Application Server 10g integrated J2EE container, portal server, HTTP server (based on Apache), and business intelligence components. It competed with IBM WebSphere and BEA WebLogic.

## Key Components

- OC4J (Oracle Containers for Java EE) for servlet and EJB hosting
- Oracle HTTP Server for web content delivery
- Oracle Portal for enterprise portal development
- Oracle Forms and Reports for legacy application hosting

## OC4J Container

OC4J was the J2EE container that hosted Java applications. It supported Servlet, JSP, EJB, and JMS specifications with Oracle-specific optimizations.

## End of Life

Oracle Application Server reached end of life as Oracle transitioned customers to Oracle Fusion Middleware built on WebLogic Server. Extended support ended for most versions.

## Migration Paths

Oracle provided migration tools and guidance for moving from OracleAS to WebLogic Server. The migration typically involved updating deployment descriptors and testing application compatibility.

## Legacy Usage

Some organizations still maintain Oracle Application Server deployments for legacy Oracle Forms and Reports applications. These systems require careful planning for migration to modern platforms.

## Modern Oracle Middleware

Oracle Fusion Middleware provides the current middleware platform built on WebLogic Server. It includes SOA Suite, Business Process Management, and integration components.
