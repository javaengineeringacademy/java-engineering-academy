# Angular Fundamentals

Angular is a platform for building mobile and desktop web applications. TypeScript-based, full-featured.

## Topics
- Components
- Templates
- Data Binding
- Directives
- Services and DI
- Routing
- Forms
- HTTP Client
- Observables
- Testing

## Learning Objectives
- Build Angular applications
- Use Angular CLI
- Implement reactive patterns

## Prerequisites
- TypeScript basics
