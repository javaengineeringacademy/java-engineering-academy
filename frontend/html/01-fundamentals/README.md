# HTML Fundamentals

## Overview
HTML (HyperText Markup Language) is the standard markup language for creating web pages.

## Topics
- Document Structure
- Elements and Tags
- Attributes
- Forms and Inputs
- Tables
- Semantic HTML
- Media Elements
- Links and Navigation
- Meta Tags
- Accessibility (ARIA)

## Learning Objectives
- Create web pages
- Use semantic HTML
- Build accessible forms

## Prerequisites
- None
