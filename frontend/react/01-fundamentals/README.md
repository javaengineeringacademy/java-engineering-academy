# React Fundamentals

## Overview
React is a JavaScript library for building user interfaces. Component-based, declarative, and powerful.

## Topics
- JSX
- Components
- Props
- State
- Lifecycle Methods
- Hooks
- Context API
- React Router
- Event Handling
- Conditional Rendering

## Learning Objectives
- Build React applications
- Use React hooks effectively
- Manage component state

## Prerequisites
- JavaScript basics
- ES6+ features
