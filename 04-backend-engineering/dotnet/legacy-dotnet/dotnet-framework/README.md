## .NET Framework History

History and evolution of .NET Framework from version 1.0 through 4.8 and the transition to .NET Core/.NET 5+.

## Overview

.NET Framework was Microsoft's original managed code platform, running from 2002 to 2019 as the primary .NET runtime. Understanding its history helps with migration decisions.

## Why It Matters

- Many enterprise systems still run on .NET Framework
- Migration requires understanding version differences
- End of support drives modernization
- Historical context for modern .NET design decisions

## Key Concepts

- **CLR**: Common Language Runtime (Framework version)
- **BCL**: Base Class Library
- **GAC**: Global Assembly Cache
- **MSBuild**: Build system
- **Web.config**: Application configuration
- **App.config**: Desktop application configuration
