## Legacy .NET

Overview of legacy .NET technologies including Web Forms, WCF, .NET Framework, Remoting, and Enterprise Services.

## Overview

Legacy .NET technologies were foundational to enterprise .NET development. While modern .NET is preferred for new projects, understanding these technologies is essential for maintaining and migrating existing systems.

## Why It Matters

- Millions of lines of legacy code exist
- Migration requires understanding existing patterns
- Some systems still run on legacy platforms
- Knowledge helps with legacy code maintenance

## Key Concepts

- **.NET Framework**: Original Windows-only runtime
- **Web Forms**: Event-driven web development model
- **WCF**: Windows Communication Foundation for services
- **Remoting**: Cross-domain communication
- **Enterprise Services**: COM+ integration
- **Windows Services**: Background processes on Windows

## Core Topics

- .NET Framework versions and lifecycle
- ASP.NET Web Forms architecture
- WCF service contracts and bindings
- .NET Remoting limitations
- COM+ integration
- Windows Services development

## Best Practices

- Plan migration strategies for legacy systems
- Keep legacy systems updated with security patches
- Consider strangler fig pattern for gradual migration
- Document legacy system behavior before migrating
