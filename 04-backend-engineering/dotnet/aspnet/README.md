## ASP.NET Ecosystem

ASP.NET is the web framework for building modern web applications, APIs, and real-time services on .NET.

## Overview

The ASP.NET ecosystem includes multiple frameworks for different web development scenarios, from traditional MVC to modern minimal APIs and Blazor for full-stack .NET web development.

## Why It Matters

- Cross-platform web development on .NET
- High-performance web frameworks
- Multiple paradigms for different use cases
- Excellent tooling and developer experience
- Large ecosystem of middleware and libraries

## Key Concepts

- **ASP.NET Core**: Cross-platform, high-performance web framework
- **MVC Pattern**: Model-View-Controller for structured web apps
- **Minimal APIs**: Lightweight API development
- **Razor**: Server-side markup for dynamic web pages
- **Blazor**: Full-stack C# web development
- **SignalR**: Real-time communication
- **Middleware Pipeline**: Request processing pipeline

## Core Topics

- ASP.NET Core architecture and middleware
- MVC pattern and conventions
- Minimal APIs for microservices
- Razor Pages for page-based scenarios
- Blazor WebAssembly and Server
- SignalR for real-time communication
- Web API design and RESTful services

## Best Practices

- Start new projects with Minimal APIs unless MVC is needed
- Use dependency injection throughout
- Implement health checks for production
- Use structured logging with ILogger
- Apply authentication and authorization middleware

## Hands-on Labs

- Build a REST API with Minimal APIs
- Create an MVC web application
- Implement a Blazor WebAssembly app
- Set up SignalR for real-time updates
- Add authentication with JWT
