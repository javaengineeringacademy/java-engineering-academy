## Azure Services Overview

Comprehensive overview of Azure services relevant to .NET application development and deployment.

## Overview

Azure offers 200+ services across compute, storage, networking, databases, AI, and more. Understanding which services to use for .NET applications is key to effective cloud architecture.

## Why It Matters

- Right service choice affects cost and performance
- Managed services reduce operational overhead
- Integration between services enables complex architectures
- Global reach with regional deployment options

## Key Concepts

- **Resource Groups**: Logical grouping of Azure resources
- **Resource Providers**: Services that manage Azure resources
- **ARM Templates**: Infrastructure as Code
- **Azure CLI/PowerShell**: Command-line management
- **Azure Portal**: Web-based management
- **Bicep**: Modern IaC language for Azure

## Core Topics

- Compute services (App Service, Functions, AKS, VMs)
- Storage services (Blob, Queue, Table, Files)
- Database services (SQL, Cosmos DB, PostgreSQL, MySQL)
- Messaging services (Service Bus, Event Hubs, Event Grid)
- Identity and access (Azure AD, Managed Identities)
- Monitoring (Application Insights, Log Analytics)

## Best Practices

- Use Azure Resource Manager for all deployments
- Implement Infrastructure as Code
- Use managed identities for service authentication
- Enable diagnostic logging for all services
- Use Azure Policy for governance

## Hands-on Labs

- Deploy infrastructure with Bicep
- Set up Azure Key Vault for secrets
- Configure Application Insights monitoring
- Create a managed identity for a web app
