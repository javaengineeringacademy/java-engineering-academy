## Why Constructor Injection

### Comparison

```java
// Field Injection (Avoid)
@Service
public class UserService {
    @Autowired
    private UserRepository userRepository;

    @Autowired
    private EmailService emailService;
}

// Setter Injection (Avoid for required dependencies)
@Service
public class UserService {
    private UserRepository userRepository;

    @Autowired
    public void setUserRepository(UserRepository userRepository) {
        this.userRepository = userRepository;
    }
}

// Constructor Injection (Recommended)
@Service
public class UserService {
    private final UserRepository userRepository;
    private final EmailService emailService;

    public UserService(UserRepository userRepository,
                       EmailService emailService) {
        this.userRepository = userRepository;
        this.emailService = emailService;
    }
}
```

### Benefits

```
1. Immutability - Fields can be final
2. Required dependencies are explicit
3. Easy to test - Just pass mock in constructor
4. Fail-fast - Missing dependencies cause startup failure
5. No reflection needed
6. Works with final keyword
```

## Basic Usage

### With @RequiredArgsConstructor

```java
@Service
@RequiredArgsConstructor
public class UserService {

    private final UserRepository userRepository;
    private final EmailService emailService;
    private final PasswordEncoder passwordEncoder;

    // Constructor generated by Lombok with all final fields
}
```

### With @Autowired

```java
@Service
public class UserService {

    private final UserRepository userRepository;
    private final EmailService emailService;

    @Autowired
    public UserService(UserRepository userRepository,
                       EmailService emailService) {
        this.userRepository = userRepository;
        this.emailService = emailService;
    }
}
```

### Multiple Constructors

```java
@Service
public class NotificationService {

    private final NotificationSender sender;
    private final TemplateEngine templateEngine;

    // Primary constructor
    public NotificationService(NotificationSender sender,
                                TemplateEngine templateEngine) {
        this.sender = sender;
        this.templateEngine = templateEngine;
    }

    // Convenience constructor with defaults
    public NotificationService(NotificationSender sender) {
        this(sender, new DefaultTemplateEngine());
    }
}
```

## With Required Args Constructor

### Lombok Configuration

```java
// pom.xml
<dependency>
    <groupId>org.projectlombok</groupId>
    <artifactId>lombok</artifactId>
    <optional>true</optional>
</dependency>

// lombok.config
config.stopBubbling = true
lombok.nonNull.annotation = jakarta.annotation.Nonnull
```

### Using @NonNull

```java
@Service
@RequiredArgsConstructor
public class OrderService {

    private final OrderRepository orderRepository;
    private final PaymentService paymentService;
    private final InventoryService inventoryService;

    public Order createOrder(CreateOrderRequest request) {
        // All dependencies guaranteed non-null
        return orderRepository.save(new Order(request));
    }
}
```

### With Optional Dependencies

```java
@Service
@RequiredArgsConstructor
public class ReportService {

    private final ReportRepository reportRepository;
    private final TemplateEngine templateEngine;

    @Setter
    private NotificationService notificationService; // Optional

    public Report generateReport(ReportRequest request) {
        Report report = createReport(request);

        if (notificationService != null) {
            notificationService.notify(report);
        }

        return report;
    }
}
```

## Testing Benefits

### Easy Unit Testing

```java
@ExtendWith(MockitoExtension.class)
class UserServiceTest {

    @Mock
    private UserRepository userRepository;

    @Mock
    private EmailService emailService;

    @InjectMocks
    private UserService userService;

    @Test
    void shouldCreateUser() {
        // Arrange
        when(userRepository.save(any())).thenReturn(testUser);

        // Act
        User result = userService.createUser(request);

        // Assert
        verify(userRepository).save(any());
        verify(emailService).sendWelcomeEmail(any());
    }
}
```

### Integration Testing

```java
@SpringBootTest
class UserServiceIntegrationTest {

    @Autowired
    private UserService userService;

    @MockBean
    private EmailService emailService;

    @Test
    void shouldCreateUser() {
        User result = userService.createUser(request);
        assertNotNull(result.getId());
    }
}
```

## Best Practices

### 1. Use Final Fields

```java
@Service
@RequiredArgsConstructor
public class UserService {
    private final UserRepository userRepository;  // Immutable
    private final EmailService emailService;     // Immutable
}
```

### 2. Limit Constructor Parameters

```java
// Good - 3-4 dependencies
@Service
@RequiredArgsConstructor
public class UserService {
    private final UserRepository userRepository;
    private final EmailService emailService;
    private final PasswordEncoder passwordEncoder;
}

// Bad - Too many dependencies (suggests bad design)
@Service
@RequiredArgsConstructor
public class TooManyDeps {
    private final ServiceA a;
    private final ServiceB b;
    private final ServiceC c;
    private final ServiceD d;
    private final ServiceE e;
    private final ServiceF f;
}
```

### 3. Avoid Circular Dependencies

```java
// Bad - Circular dependency
@Service
public class ServiceA {
    public ServiceA(ServiceB b) {}
}

@Service
public class ServiceB {
    public ServiceB(ServiceA a) {}
}

// Good - Extract shared logic
@Service
public class SharedService {
    // Common logic
}

@Service
public class ServiceA {
    public ServiceA(SharedService shared) {}
}

@Service
public class ServiceB {
    public ServiceB(SharedService shared) {}
}
```

### 4. Use Interfaces

```java
@Service
@RequiredArgsConstructor
public class NotificationService {
    private final NotificationSender sender;  // Interface, not implementation
}

// Multiple implementations
@Component
@Qualifier("email")
public class EmailSender implements NotificationSender { }

@Component
@Qualifier("sms")
public class SmsSender implements NotificationSender { }
```

### 5. Document Dependencies

```java
@Service
@RequiredArgsConstructor
public class PaymentService {
    private final PaymentGateway gateway;     // Stripe/PayPal integration
    private final FraudDetector fraudDetector; // Fraud detection service
    private final ReceiptGenerator receipt;    // Receipt generation
}
```
