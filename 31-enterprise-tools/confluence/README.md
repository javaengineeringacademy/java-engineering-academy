# Confluence - Documentation and Knowledge Management

## Overview

Confluence is Atlassian's collaborative documentation platform used for creating, organizing, and sharing knowledge across teams. It serves as a central wiki for technical documentation, project plans, meeting notes, and organizational knowledge bases.

## Why It Matters

- Centralizes documentation in a searchable, versioned platform
- Enables real-time collaboration on documents and technical specs
- Integrates with Jira for linking documentation to work items
- Supports structured knowledge management with spaces and page hierarchies
- Provides templates for consistent documentation formats

## Key Concepts

- **Space**: Top-level container for related pages and content
- **Page**: Individual document within a space with hierarchical nesting
- **Blog Post**: Time-styled content for announcements and updates
- **Template**: Reusable page structures for consistent formatting
- **Macro**: Embedded components for dynamic content (Jira links, code blocks, diagrams)
- **Page Tree**: Hierarchical navigation of pages within a space

## Core Topics

### Content Organization
- Space design patterns for different team functions
- Page hierarchy and parent-child relationships
- Labels and metadata for content categorization

### Collaboration Features
- Inline and page-level comments
- @mentions and notifications for team awareness
- Page restrictions for access control

### Templates and Macros
- Creating custom page templates for recurring documentation needs
- Using macros for embedded content and dynamic data
- Blueprint templates for structured workflows

### Search and Discovery
- Full-text search across all spaces
- Advanced search with CQL (Confluence Query Language)
- Page analytics for usage tracking

## Best Practices

1. Define a clear space structure before creating content
2. Use templates to enforce documentation standards
3. Establish naming conventions for pages and spaces
4. Regularly archive outdated content and maintain a content calendar
5. Link related pages and use labels for discoverability
6. Set page restrictions for sensitive information
