# React Native Fundamentals

## Overview
React Native lets you build mobile apps using only JavaScript. Learn once, write anywhere.

## Topics
- Components
- JSX
- Props and State
- Navigation
- Styling
- Networking
- AsyncStorage
- Native Modules
- Animations
- Testing

## Learning Objectives
- Build React Native apps
- Use native features
- Deploy to stores

## Prerequisites
- React basics
- JavaScript knowledge
