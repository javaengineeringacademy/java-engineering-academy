# Cyber Security Fundamentals

## Overview
Cyber security encompasses technologies, processes, and practices to protect networks, devices, and data.

## Topics
- CIA Triad
- Authentication vs Authorization
- Encryption
- Network Security
- Web Application Security
- OWASP Top 10
- Penetration Testing
- Security Auditing
- Incident Response
- Compliance

## Learning Objectives
- Identify security threats
- Implement security controls
- Follow security best practices

## Prerequisites
- Networking basics
- Web development basics
