# GraphQL Fundamentals

## Overview
GraphQL is a query language for APIs and a runtime for fulfilling queries with existing data.

## Topics
- Schema Definition
- Queries
- Mutations
- Subscriptions
- Resolvers
- Types and Interfaces
- Input Types
- Directives
- Pagination
- Security

## Learning Objectives
- Design GraphQL schemas
- Implement resolvers
- Optimize query performance

## Prerequisites
- REST API basics
