# Serverless with AWS

## Overview
Serverless applications using AWS Lambda, API Gateway, DynamoDB, and SQS.

## Components
- AWS Lambda for compute
- API Gateway for HTTP endpoints
- DynamoDB for NoSQL storage
- SQS for async messaging
- Step Functions for workflows

## Best Practices
1. Use Lambda layers for shared dependencies
2. Implement dead letter queues
3. Use DAX for caching
4. Monitor with CloudWatch and X-Ray
