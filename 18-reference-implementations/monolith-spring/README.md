# Monolith with Spring Boot

## Overview
Well-structured Spring Boot monolith with clean architecture.

## Layers
1. API Layer (Controllers)
2. Application Layer (Services)
3. Domain Layer (Entities)
4. Infrastructure Layer (Repositories)

## Best Practices
1. Separate concerns with clear boundaries
2. Use DTOs for API contracts
3. Implement validation at API layer
4. Use transactions at service layer
5. Keep domain logic pure
