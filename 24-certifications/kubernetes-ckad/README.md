# Certified Kubernetes Application Developer (CKAD)

## Overview
The CKAD certification validates skills in designing, building, configuring, and exposing cloud-native applications running on Kubernetes.

## Domains
1. Application Design and Build (20%)
2. Application Deployment (20%)
3. Application Environment, Configuration and Security (25%)
4. Application Observability and Maintenance (15%)
5. Application Networking (20%)

## Exam Details
- Duration: 2 hours
- Format: Performance-based (hands-on terminal)
- Passing Score: 67%
- Cost: $395 USD
- Validity: 3 years

- Pod configuration and multi-container patterns
- Deployments, rollouts, and rollbacks
- Services and Ingress networking
- ConfigMaps, Secrets, and Security Contexts
- Resource limits and requests
- Health probes (liveness, readiness, startup)
- Debugging applications in Kubernetes
