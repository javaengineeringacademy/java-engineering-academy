# Certified Kubernetes Administrator

## Exam Details
- Code: CKA
- Duration: 2 hours
- Format: Performance-based
- Cost: $395

## Domains
1. Cluster Architecture (25%)
2. Workloads and Scheduling (15%)
3. Services and Networking (20%)
4. Storage (10%)
5. Troubleshooting (30%)

## Study Plan
1. Weeks 1-2: Cluster setup and management
2. Weeks 3-4: Workloads and scheduling
3. Weeks 5-6: Services and networking
4. Weeks 7-8: Storage and troubleshooting
5. Weeks 9-10: Practice labs
