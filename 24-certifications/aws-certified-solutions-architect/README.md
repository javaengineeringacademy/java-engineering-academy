# AWS Certified Solutions Architect - Associate

## Exam Details
- Code: SAA-C03
- Duration: 130 minutes
- Questions: 65
- Passing Score: 720/1000
- Cost: $150

## Domains
1. Secure Architectures (30%)
2. Resilient Architectures (26%)
3. High-Performing Architectures (24%)
4. Cost-Optimized Architectures (20%)

## Key Services
- EC2, ECS, Lambda
- S3, EBS, EFS
- VPC, Route 53, CloudFront
- RDS, DynamoDB, ElastiCache
- IAM, KMS, WAF
- SQS, SNS, EventBridge

## Study Plan
1. Weeks 1-2: Core services (compute, storage, networking)
2. Weeks 3-4: Database and caching
3. Weeks 5-6: Security and IAM
4. Weeks 7-8: Architecture patterns
5. Weeks 9-10: Practice exams and review
