# AWS Certified SysOps Administrator

## Exam Details
- Code: SOA-C02
- Duration: 180 minutes
- Questions: 65
- Passing Score: 750/1000
- Cost: $150

## Domains
1. Monitoring, Logging, and Remediation (20%)
2. Reliability and Business Continuity (16%)
3. Deployment, Provisioning, and Automation (18%)
4. Security and Compliance (16%)
5. Networking and Content Delivery (18%)
6. Cost and Performance Optimization (12%)

## Key Services
- CloudWatch, CloudTrail, Config
- Auto Scaling, ELB, Route 53
- CloudFormation, OpsWorks
- SSM, Inspector, GuardDuty

## Study Plan
1. Weeks 1-2: Monitoring and logging
2. Weeks 3-4: High availability and recovery
3. Weeks 5-6: Deployment and provisioning
4. Weeks 7-8: Security and networking
5. Weeks 9-10: Practice exams
