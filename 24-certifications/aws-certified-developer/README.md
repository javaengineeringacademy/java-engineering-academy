# AWS Certified Developer - Associate

## Exam Details
- Code: DVA-C02
- Duration: 130 minutes
- Questions: 65
- Passing Score: 720/1000
- Cost: $150

## Domains
1. Deployment (22%)
2. Security (26%)
3. Development with AWS Services (24%)
4. Testing and Debugging (18%)
5. Optimization (10%)

## Key Services
- Lambda, API Gateway, DynamoDB
- S3, SQS, SNS
- CodeBuild, CodeDeploy, CodePipeline
- CloudFormation, CDK
- X-Ray, CloudWatch

3. Weeks 5-6: Security and IAM
4. Weeks 7-8: Monitoring and debugging
5. Weeks 9-10: Practice exams
