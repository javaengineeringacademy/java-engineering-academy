# Event Storming

## Overview

Collaborative workshop technique for discovering domain events and aggregates.

## Process

1. **Domain Events**: Orange sticky notes
2. **Commands**: Blue sticky notes
3. **Aggregates**: Yellow sticky notes
4. **Policies**: Purple sticky notes
5. **Read Models**: Green sticky notes
6. **External Systems**: Pink sticky notes

## Output

```
[Command] -> [Aggregate] -> [Domain Event] -> [Policy] -> [Read Model]
```

## Benefits

- Shared understanding
- Domain discovery
- Boundary identification
- Quick iteration
