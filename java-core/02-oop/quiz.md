# OOP Concepts Quiz

## Quiz 1: Classes and Objects

### Question 1
What is a class in Java?
- A) A blueprint for objects
- B) An object itself
- C) A method
- D) A variable

**Answer: A**

### Question 2
How do you create an object in Java?
- A) Class obj = new Class();
- B) Class obj = Class.new();
- C) new Class obj = Class();
- D) object obj = new Class();

**Answer: A**

### Question 3
What is the default access modifier for class members?
- A) public
- B) private
- C) protected
- D) package-private

**Answer: D**

### Question 4
What is a constructor?
- A) A special method to initialize objects
- B) A regular method
- C) A variable
- D) A class

**Answer: A**

### Question 5
Can a class have multiple constructors?
- A) Yes
- B) No
- C) Only in Java 8+
- D) Only with inheritance

**Answer: A**

## Quiz 3: Polymorphism

### Question 1
What is polymorphism?
- A) Many forms
- B) One form
- C) No form
- D) Static form

**Answer: A**

### Question 2
What is compile-time polymorphism?
- A) Method overloading
- B) Method overriding
- C) Both A and B
- D) Neither

**Answer: A**

### Question 3
What is runtime polymorphism?
- A) Method overloading
- B) Method overriding
- C) Both A and B
- D) Neither

**Answer: B**

### Question 4
Can we override static methods?
- A) Yes
- B) No
- C) Only in same class
- D) Only in subclass

**Answer: B**

### Question 5
What is dynamic method dispatch?
- A) Runtime method call based on object type
- B) Compile-time method call
- C) Static method call
- D) Constructor call

## Quiz 5: Abstraction

### Question 1
What is abstraction?
- A) Hiding implementation details
- B) Showing implementation details
- C) Hiding data
- D) Showing data

**Answer: A**

### Question 2
What is the difference between abstract class and interface?
- A) Abstract class can have constructors, interface cannot
- B) Interface can have constructors
- C) Both can have constructors
- D) Neither can have constructors

**Answer: A**

### Question 3
Can an abstract class have non-abstract methods?
- A) Yes
- B) No
- C) Only in Java 8+
- D) Only with interfaces

**Answer: A**

### Question 4
Can an interface have final variables?
- A) Yes
- B) No
- C) Only in Java 8+
- D) Only with abstract classes

**Answer: A**

### Question 5
What is a functional interface?
- A) Interface with one abstract method
- B) Interface with no methods
- C) Interface with multiple methods
- D) Abstract class

**Answer: A**
