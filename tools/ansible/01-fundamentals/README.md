# Ansible Fundamentals

## Overview
Ansible is an open-source automation tool for configuration management, deployment, and orchestration.

## Topics
- Inventory
- Playbooks
- Tasks
- Handlers
- Variables
- Templates (Jinja2)
- Roles
- Modules
- Galaxy
- Vault

## Learning Objectives
- Write Ansible playbooks
- Manage infrastructure
- Automate deployments

## Prerequisites
- Linux basics
- SSH concepts
