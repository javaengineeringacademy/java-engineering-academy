# Data Engineering Fundamentals

## Overview
Data Engineering involves designing, building, and maintaining data systems and pipelines.

## Topics
- ETL/ELT Pipelines
- Data Warehousing
- Data Lakes
- Apache Spark
- Apache Kafka
- Airflow
- dbt
- Data Modeling
- Data Quality
- Governance

## Learning Objectives
- Design data pipelines
- Use ETL tools
- Implement data quality checks

## Prerequisites
- SQL proficiency
- Programming basics
