- Code: AZ-305
- Duration: 120 minutes
- Cost: $165

## Domains
1. Design identity, governance, and data solutions
2. Design infrastructure solutions
3. Design business continuity solutions
4. Design platform solutions

- Virtual Machines, App Service
- Azure SQL, Cosmos DB
- Virtual Network, Azure Front Door

3. Weeks 5-6: Security and identity
