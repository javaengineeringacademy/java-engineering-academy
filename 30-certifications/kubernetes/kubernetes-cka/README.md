# Certified Kubernetes Administrator (CKA)

## Overview
The CKA certification validates skills in Kubernetes cluster administration, including maintenance, troubleshooting, networking, storage, and security.

## Domains
1. Cluster Architecture, Installation & Configuration (25%)
2. Workloads & Scheduling (15%)
3. Services & Networking (20%)
4. Storage (10%)
5. Troubleshooting (30%)

## Exam Details
- Duration: 2 hours
- Format: Performance-based (hands-on terminal)
- Passing Score: 67%
- Cost: $395 USD
- Validity: 3 years
