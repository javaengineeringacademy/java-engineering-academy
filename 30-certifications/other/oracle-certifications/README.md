# Oracle Java Certifications

## OCA - Oracle Certified Associate
- Java SE Programmer I
- Topics: Java basics, OOP, exceptions, collections

## OCP - Oracle Certified Professional
- Java SE Programmer II
- Topics: Advanced Java, streams, concurrency, modules

## Study Plan
1. Weeks 1-4: Core Java concepts
2. Weeks 5-8: OOP and collections
3. Weeks 9-12: Advanced topics
4. Weeks 13-14: Practice exams
