# Red Hat Certifications

## RHCSA - Red Hat Certified System Administrator
- Duration: 2.5 hours
- Format: Performance-based
- Topics: Essential system administration tasks

## RHCE - Red Hat Certified Engineer
- Duration: 3.5 hours
- Format: Performance-based
- Topics: Advanced system administration with Ansible

## Key Topics
- System configuration
- File systems and storage
- Users and groups
- Networking
- Security
- Containers
- Ansible automation
