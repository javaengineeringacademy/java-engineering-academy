# Documentation

This directory contains long-form project documentation that supports the curriculum, architecture, roadmap, and
maintainer workflows.

## Sections

- [Architecture](architecture/README.md): repository design, module boundaries, and build conventions.
- [Interview](interview/README.md): interview preparation strategy and planned question tracks.
- [Roadmap](roadmap/README.md): detailed delivery planning for curriculum milestones.

Documentation should be versioned with the repository so learners can trust that examples, exercises, and build
instructions evolve together.
