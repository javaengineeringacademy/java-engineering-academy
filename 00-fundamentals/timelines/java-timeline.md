# Java Timeline

## Overview

Java has evolved from a set-top box programming language to one of the most widely used enterprise platforms, consistently adapting to changing industry needs.

---

## 1991-1995: Origins

### Green Project (1991)
- **Team**: James Gosling, Mike Sheridan, Patrick Naughton
- **Goal**: Programming for consumer electronics
- **Language name**: Oak (later renamed Java)
- **Target**: Set-top boxes, TVs, VCRs

### Java Renamed (1995)
- Oak trademarked by Oak Technology
- Renamed to Java (coffee reference)
- Partnership with Netscape浏览器

### Java 1.0 (1996)
- **Release**: January 23, 1996
- **Features**: Applets, AWT, basic language
- **Promise**: Write Once, Run Anywhere
- **Impact**: Browser-based applications

---

## 1997-2000: Growing Pains

### Java 1.1 (1997)
- Inner classes
- JavaBeans
- JDBC database connectivity
- Reflection API
- Event delegation model

### Java 2 (1998)
- **J2SE**: Standard Edition
- **J2EE**: Enterprise Edition
- **J2ME**: Micro Edition
- Collections framework
- Swing GUI
- JIT compilation

### Java 1.3 (2000)
- HotSpot JVM
- Performance improvements
- JNDI (Naming and Directory Interface)
- Sound API

---

## 2001-2004: Enterprise Maturity

### Java 1.4 (2002)
- NIO (Non-blocking I/O)
- Regular expressions
- Assertions
- Logging API
- XML processing

### Java 5 (2004)
- **Generics**: Type-safe collections
- **Autoboxing**: Primitive-wrapper conversion
- **Enums**: Type-safe enumerations
- **Varargs**: Variable arguments
- **Enhanced for loop**: Iteration syntax
- **Annotations**: Metadata
- **Concurrency utilities**: java.util.concurrent
- **Impact**: Major productivity improvement

---

## 2005-2010: Modernization

### Java 6 (2006)
- Scripting engine support
- JDBC 4.0
- Improved performance
- Web services support
- Compiler API

### Java 7 (2011)
- **Diamond operator**: <>
- **Try-with-resources**: Automatic resource management
- **String in switch**: String comparison
- **NIO.2**: Modern file I/O
- **InvokeDynamic**: Dynamic language support
- **Fork/Join**: Parallel processing

---

## 2011-2017: Rapid Evolution

### Java 8 (2014)
- **Lambda expressions**: Functional programming
- **Stream API**: Data processing
- **Optional**: Null handling
- **Date/Time API**: java.time package
- **Method references**: Concise syntax
- **Interface default methods**: Evolution support
- **Impact**: Functional programming in Java

### Java 9 (2017)
- **Module system**: JPMS
- **JShell**: REPL
- **HTTP/2 client**: Modern networking
- **Interface private methods**: Better encapsulation
- **Multi-release JARs**: Version flexibility

### Java 10 (2018)
- Local variable type inference (var)

### Java 11 (2018)
- LTS release
- HTTP Client standard
- String methods (strip, isBlank)
- Single-file source execution
- ZGC experimental

---

## 2019-2023: Innovation Acceleration

### Java 12-16
- Switch expressions
- Text blocks
- Records (16)
- Pattern matching for instanceof (16)
- Sealed classes (17)

### Java 17 (2021)
- **LTS release**
- Sealed classes
- Pattern matching preview
- Foreign Function API (incubator)
- Strong encapsulation

### Java 18-20
- Simple web server
- Code snippets in javadoc
- Virtual threads (preview)
- Structured concurrency (incubator)
- Scoped values (incubator)

### Java 21 (2023)
- **LTS release**
- **Virtual threads**: Lightweight concurrency
- **Pattern matching**: switch enhancements
- **Record patterns**: Destructuring
- **Sealed classes**: Finalized
- **String templates**: (preview)
- **Impact**: Modern concurrent programming

---

## 2024-2025: Future Direction

### Java 22-24
- Unnamed variables
- Statements before super()
- Module import declarations
- Stream gatherers
- Flexible constructor bodies

### Java 25 (2024)
- **LTS release**
- Stabilized features from previews
- Performance improvements
- continued VM optimization

### Key Trends
- Virtual threads mainstream adoption
- Ahead-of-time compilation improvements
- Native image optimization
- AI/ML integration support
