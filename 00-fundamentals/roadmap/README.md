# Roadmap Notes

This directory contains planning notes that support the public [ROADMAP.md](../../ROADMAP.md). Public roadmap entries
should stay outcome-oriented, while documents here can capture sequencing, dependencies, and implementation details.

## Planning Rules

- Tie work to learner outcomes.
- Keep milestones small enough to review and release.
- Prefer working examples before broad theory.
- Add automation when it improves contributor confidence.
- Revisit the roadmap after each completed module.
