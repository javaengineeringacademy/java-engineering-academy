# Interview Documentation

Interview preparation material will connect Java language knowledge with practical problem solving and clear
communication.

## Planned Tracks

- Java language depth.
- Object-oriented design.
- Collections and generics.
- Concurrency and performance.
- Data structures and algorithms.
- System design and production trade-offs.
- Code review and debugging scenarios.

Each track should include learning goals, representative prompts, solution walkthroughs, and evaluation rubrics.
